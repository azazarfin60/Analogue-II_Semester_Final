# Cascode Configuration
> **Topic:** Multistage Amplifiers | **Priority:** 🟢 OCCASIONAL | **Exam Frequency:** 3/8 years

## Basic Knowledge: The High-Frequency Problem

A common emitter (CE) amplifier provides great voltage gain. But it has a big problem at high frequencies. We call this problem the **Miller effect**. 

Every transistor has tiny internal capacitors. One of these sits between the base and the collector. We call it the collector-base capacitance ($C_{bc}$). In a regular CE amplifier, the circuit multiplies this capacitance by the total voltage gain. This creates a massive capacitance at the input. 

High capacitance at the input acts like a short circuit for high-frequency signals. It ruins the amplifier's bandwidth. The amplifier stops working well at high frequencies.

We use the cascode amplifier to solve this problem. 

## The Cascode Solution

The cascode amplifier stacks two transistors together. It uses a common-emitter (CE) stage on the bottom. It uses a common-base (CB) stage on top. 

The bottom CE stage takes the input and amplifies the current. The top CB stage takes that current and passes it to the output. The top stage also provides the voltage swing. 

Because of the top stage, the bottom stage only needs to produce a voltage gain of about 1. Since the voltage gain of the bottom stage is so small, the Miller effect almost disappears. 

You get the high voltage gain of a CE amplifier. You also get the wide bandwidth of a CB amplifier. It combines the best features of both.

## The Circuit Diagram

```
                  V_CC
                   |
         +----+----+---------------+
         |    |                    |
        [R1]  |                  [R_C]
         |    |                    |
         +----+------- Base(Q2)    |
         |    |                    |
        [R2]  |                Q2 (CB Stage)
         |    |                    |
        [R3]  |         +----------+
         |    |         |   (V_C1 = V_E2)
        ===   |       Q1 (CE Stage)
        GND   |         |
              |        [R_E]
              |         |
             ===       ===
             GND       GND
```

- **Q1 (bottom)** is in a Common-Emitter setup. It amplifies the input signal.
- **Q2 (top)** is in a Common-Base setup. It passes the current through, gives high output impedance, and stops the Miller effect.

## Step-by-Step DC Bias Analysis

The resistor chain $R_1, R_2$, and $R_3$ creates a voltage divider. This provides the bias voltages for the bases of both transistors.

**Step 1: Find the base voltages.**

The voltage at the base of Q1 is:

$$
V_{B1} = \frac{R_3}{R_1 + R_2 + R_3} \cdot V_{CC}
$$

The voltage at the base of Q2 is:

$$
V_{B2} = \frac{R_2 + R_3}{R_1 + R_2 + R_3} \cdot V_{CC}
$$

**Step 2: Find the emitter current for Q1.**

We subtract the base-emitter voltage drop ($V_{BE1}$) from $V_{B1}$ to get the emitter voltage. Then we divide by $R_E$:

$$
I_{E1} = \frac{V_{B1} - V_{BE1}}{R_E}
$$

**Step 3: Track the current through the stack.**

Both transistors connect in series. This means the same current flows through both of them. The collector current of Q1 equals the emitter current of Q2. 

$$
I_{C2} \approx I_{E2} \approx I_{C1} \approx I_{E1}
$$

**Step 4: Find the output voltage.**

We calculate the voltage at the top collector (Q2):

$$
V_{C2} = V_{CC} - I_{C2} R_C
$$

## How the Miller Effect Disappears

The Miller effect formula is $C_{Miller} = C_{bc}(1 + |A_v|)$. 

In a standard CE amplifier, the voltage gain ($|A_v|$) can be 100 to 300. This makes $C_{Miller}$ huge.

In the cascode circuit, the CE stage (Q1) connects to the emitter of Q2. The emitter of Q2 has a very low input impedance. This means Q1 sees a very small load.

The voltage gain at Q1's collector becomes very small. It is approximately:

$$
A_{v1} \approx \frac{-g_m \cdot r_{e2}}{1} \approx -1 \quad (\text{if transistors match})
$$

So the Miller capacitance becomes $C_{bc}(1+1) = 2C_{bc}$. This is a very small value. The bandwidth stays wide.

The overall voltage gain of the whole circuit is still high. Q2 provides the full voltage swing across the load resistor $R_C$:

$$
A_v \approx -g_m \cdot R_C
$$

This is the exact same gain as a normal CE stage.

## Key Results Comparison

| Feature | CE Amplifier Alone | Cascode Amplifier |
|---|---|---|
| **Voltage Gain** | $-g_m R_C$ | $-g_m R_C$ (same) |
| **Output Impedance** | $r_o$ | $\beta \cdot r_o$ (much higher) |
| **Bandwidth** | Limited by Miller effect | Much wider |
| **Input Impedance** | $\beta r_e$ | $\beta r_e$ (same) |

## ⚡ Exam Tips

- If the exam asks for the "advantages of a cascode", list these four things: 
  1. It stops the Miller effect.
  2. It has higher bandwidth.
  3. It has much higher output impedance.
  4. It keeps the same high voltage gain as a CE amplifier.
- For DC analysis problems, remember that the currents are roughly equal through the entire stack. Set $I_{C1} \approx I_{E2} \approx I_{C2}$.
