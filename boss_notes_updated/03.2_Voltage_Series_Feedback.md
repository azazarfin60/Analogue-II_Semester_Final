# Voltage-Series Feedback Derivations
> **Topic:** Feedback Amplifiers | **Priority:** 🟡 IMPORTANT | **Exam Frequency:** 4/8 years

## Basic Knowledge: The Desensitivity Factor

In every single negative feedback calculation, you will see one specific term appear over and over. That term is $(1 + A\beta)$. We call this the **Desensitivity Factor**. We often write it simply as $D$.

Let's break down its parts:
- $A$ is the open-loop gain. This is the raw, maximum voltage gain of the amplifier with no feedback connected.
- $\beta$ is the feedback factor. This is the tiny fraction of the output signal that we send back to the input.
- $A\beta$ is the loop gain. This is the total gain of the signal as it travels in a full circle around the loop.

In a Voltage-Series feedback amplifier, negative feedback creates a trade-off. We throw away some of our raw voltage gain. In return, the amplifier improves in almost every other way. It gains better stability, wider bandwidth, higher input impedance, and lower output impedance. 

The amazing thing is that every single one of these improvements scales by exactly the same factor: $D = 1 + A\beta$. Exams frequently ask you to prove this mathematically. 

---

## 1. Bandwidth Expansion Proof
*[Appeared in: 2024 Q3(b)]*

We must prove that negative feedback pushes the upper cutoff frequency higher and the lower cutoff frequency lower. This expands the total bandwidth by $(1 + A\beta)$.

**Step 1: The Closed-Loop Gain Equation**
We start with the fundamental equation for any negative feedback system. 

$$
A_f(f) = \frac{A(f)}{1 + A(f)\beta}
$$

**Step 2: Upper Cutoff Frequency ($f_{Hf}$)**
We know that the high-frequency response of the raw amplifier falls off according to this formula:

$$
A(f) = \frac{A_{mid}}{1 + j(f/f_H)}
$$

Substitute this into the feedback equation:

$$
A_f(f) = \frac{ \frac{A_{mid}}{1 + j(f/f_H)} }{ 1 + \beta \left( \frac{A_{mid}}{1 + j(f/f_H)} \right) }
$$

Multiply the top and bottom by $1 + j(f/f_H)$ to clear out the messy fractions:

$$
A_f(f) = \frac{A_{mid}}{1 + j(f/f_H) + A_{mid}\beta} = \frac{A_{mid}}{(1 + A_{mid}\beta) + j(f/f_H)}
$$

Now, divide the top and bottom by $(1 + A_{mid}\beta)$ to get it into the standard format:

$$
A_f(f) = \frac{ \frac{A_{mid}}{1 + A_{mid}\beta} }{ 1 + j\left( \frac{f}{f_H (1 + A_{mid}\beta)} \right) }
$$

Look at the denominator. The new upper cutoff frequency is clearly visible right there:

$$
\boxed{ f_{Hf} = f_H (1 + A_{mid}\beta) }
$$

The upper cutoff moved higher by the factor $(1+A\beta)$.

**Step 3: Lower Cutoff Frequency ($f_{Lf}$)**
We can do the exact same math using the low-frequency response equation ($A(f) = \frac{A_{mid}}{1 - j(f_L/f)}$). We get:

$$
\boxed{ f_{Lf} = \frac{f_L}{1 + A_{mid}\beta} }
$$

The lower cutoff moved lower by the factor $(1+A\beta)$.

**Step 4: Overall Bandwidth ($BW_f$)**
Bandwidth is $f_H - f_L$. We assume $f_H$ is much larger than $f_L$. 

$$
BW_f \approx f_{Hf} = f_H (1 + A\beta) \approx \boxed{ BW_{open} \times (1 + A\beta) }
$$

**Proof Complete!** The bandwidth expanded exactly as expected.

## 2. Input Impedance ($Z_{if}$) Proof
*[Appeared in: 2021 Q2(b), 2018 Q6(a)]*

We must prove that series input mixing increases the input impedance by $(1 + A\beta)$.

**Step 1: Define the voltages**
In a series connection, the feedback voltage ($V_f = \beta V_o$) sits in series with the external source voltage ($V_s$). They fight each other. The actual voltage reaching the amplifier ($V_i$) is the difference between them:

$$
V_i = V_s - V_f = V_s - \beta V_o
$$

**Step 2: Relate to the source voltage**
We know the output voltage is $V_o = A V_i$. Substitute this into the formula:

$$
V_i = V_s - \beta (A V_i)
$$

Rearrange the terms to solve for the source voltage $V_s$:

$$
V_s = V_i + A\beta V_i = V_i(1 + A\beta)
$$

**Step 3: Calculate Impedance**
By Ohm's law, the input impedance seen by the source is $Z_{if} = V_s / I_i$. We also know the raw amplifier has an input impedance $Z_i = V_i / I_i$.

Substitute our equation for $V_s$ into the $Z_{if}$ equation:

$$
Z_{if} = \frac{V_i(1 + A\beta)}{I_i}
$$

Since $V_i / I_i = Z_i$, we get:

$$
\boxed{ Z_{if} = Z_i (1 + A\beta) }
$$

**Proof Complete!** The input impedance increased.

---

## 3. Output Impedance ($Z_{of}$) Proof

We must prove that parallel output sampling decreases the output impedance by $(1 + A\beta)$.

**Step 1: The test voltage method**
To find output impedance mathematically, we must turn off the main input source ($V_s = 0$). Then, we apply a fake "test voltage" ($V_t$) directly to the output terminal. The impedance will be $V_t$ divided by whatever current ($I_t$) gets drawn into the amplifier.

**Step 2: Calculate the current $I_t$**
The current flowing into the amplifier output is driven by a voltage difference. It is the difference between our test voltage $V_t$ and the amplifier's internal dependent voltage source ($A V_i$). This voltage acts across the internal output resistance $Z_o$:

$$
I_t = \frac{V_t - A V_i}{Z_o}
$$

**Step 3: Find $V_i$**
Since the main source is turned off ($V_s = 0$), the only signal reaching the input is the feedback signal. The feedback network reads our test voltage $V_t$ and sends back $\beta V_t$. Because this is negative feedback, the input sees $V_i = -V_f = -\beta V_t$.

**Step 4: Substitute and Solve**
Substitute $V_i = -\beta V_t$ into the current equation:

$$
I_t = \frac{V_t - A(-\beta V_t)}{Z_o} = \frac{V_t(1 + A\beta)}{Z_o}
$$

Rearrange the terms to find $Z_{of} = V_t / I_t$:

$$
\boxed{ Z_{of} = \frac{Z_o}{1 + A\beta} }
$$

**Proof Complete!** The output impedance decreased.

## ⚡ Exam Tips

- **Read carefully.** Exams will often ask you to "prove that Voltage-Series feedback improves input and output resistance." This means you must do both derivation #2 and #3 above.
- **The zero-source trick.** The most important trick for the output impedance proof is remembering the "Test Voltage" method. You must set $V_s = 0$. If you forget to start with $V_s=0$, the math becomes impossible.
