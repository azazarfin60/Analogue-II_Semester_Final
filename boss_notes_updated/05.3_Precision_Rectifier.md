# Precision Rectifiers
> **Topic:** Op-Amp Applications | **Priority:** 🟡 IMPORTANT | **Exam Frequency:** 3/8 years

## Basic Knowledge: The Diode Drop Problem

Rectification is the process of converting an alternating current (AC) signal into a direct current (DC) signal. We usually do this using a diode. A diode is a one-way valve for electricity. It lets current flow in one direction but blocks it in the other.

However, a standard silicon diode is not a perfect valve. It requires a small push to open the gate. This push is the forward voltage drop. It is usually about 0.7V. 

If you try to rectify a tiny 100 mV AC signal using a standard diode, absolutely nothing will happen. The 100 mV signal is simply not strong enough to overcome the 0.7V threshold. The diode gate stays firmly shut. The signal is lost.

To rectify very small signals (like those from medical sensors or audio microphones), we need a "Super Diode" that has zero voltage drop. We can build one using an op-amp.

## 1. Precision Half-Wave Rectifier
*[Appeared in: 2020 Q7(c), 2019 Q5(b)]*

We build a precision rectifier by placing the diode *inside* the feedback loop of an operational amplifier. The massive open-loop gain of the op-amp essentially divides the 0.7V drop by 200,000. It turns it into an effective drop of $0.000003\text{ V}$.

### The Circuit Diagram

```
                  D1 (Cathode)
              +----|<-----+
              |           |
        Vin o-(+)--[ Av ]-o----> Vout
              |           |
              +-----------+
```
*(Note: A load resistor $R_L$ is usually connected from $V_{out}$ to ground).*

### How it Works

**Case 1: Positive Half-Cycle ($V_{in} > 0$)**
1. The input voltage goes slightly positive.
2. The op-amp amplifies this tiny positive voltage. It swings its output sharply positive.
3. This positive voltage easily overcomes the 0.7V drop and forward-biases the diode $D_1$.
4. The diode conducts. This closes the feedback loop.
5. With the loop closed, the circuit acts exactly like a standard voltage follower. By the virtual short principle, $V_- = V_+$. Therefore, the output voltage perfectly tracks the input voltage.

$$
\boxed{ V_{out} = V_{in} }
$$

**Case 2: Negative Half-Cycle ($V_{in} < 0$)**
1. The input voltage goes slightly negative.
2. The op-amp amplifies this. It swings its output sharply down to negative saturation ($-V_{sat}$).
3. This massive negative voltage completely reverse-biases the diode $D_1$.
4. The diode turns OFF. This physically breaks and opens the feedback loop.
5. With the loop broken, the op-amp is totally disconnected from the output node. The load resistor pulls the output node safely down to ground.

$$
\boxed{ V_{out} = 0\text{V} }
$$

## 2. Precision Full-Wave Rectifier
*[Appeared in: 2023 Q8(a)]*

A full-wave precision rectifier takes the absolute value of the input signal. It is often called an Absolute Value Circuit. We build it by cascading two stages: a half-wave rectifier and an inverting summer.

### The Logic
We want $V_{out} = |V_{in}|$.
- If $V_{in} = +5\text{V}$, we want $V_{out} = +5\text{V}$.
- If $V_{in} = -5\text{V}$, we want $V_{out} = +5\text{V}$.

### The Circuit Architecture
1. Feed the input $V_{in}$ into an **Inverting Summer** with a gain of -1.
2. Feed the exact same input $V_{in}$ into an **Inverting Half-Wave Rectifier**.
   - This special half-wave rectifier outputs $-V_{in}$ during positive cycles. It outputs 0V during negative cycles.
3. Feed the output of this half-wave rectifier into the same Inverting Summer, but give it a gain of -2.

### The Mathematical Proof

**During a Positive Cycle (e.g., $V_{in} = +5\text{V}$):**
- The half-wave rectifier is active. It outputs $-V_{in}$ (-5V).
- The summer receives the original +5V (multiplied by a gain of -1). 
- The summer ALSO receives the rectifier's -5V (multiplied by a gain of -2).
- Summer Output = $-(1 \times 5\text{V} + 2 \times -5\text{V}) = -(5 - 10) = -(-5) = \mathbf{+5\text{V}}$.

**During a Negative Cycle (e.g., $V_{in} = -5\text{V}$):**
- The half-wave rectifier is OFF. It outputs 0V.
- The summer receives the original -5V (multiplied by a gain of -1). 
- The summer ALSO receives the rectifier's 0V (multiplied by a gain of -2).
- Summer Output = $-(1 \times -5\text{V} + 2 \times 0\text{V}) = -(-5 + 0) = \mathbf{+5\text{V}}$.

In both cases, the final output is positive. The circuit successfully takes the absolute value!

- **The key justification.** If the exam asks why we use them, write this exact phrase: **"To overcome the 0.7V threshold voltage of standard silicon diodes for small-signal rectification."**
- **Show the math.** For the full-wave explanation, explicitly break it down into the "Positive Cycle" math and the "Negative Cycle" math as shown above. This proves to the examiner that you understand how the two channels sum together.
