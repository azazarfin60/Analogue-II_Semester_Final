# The Four Feedback Topologies
> **Topic:** Feedback Amplifiers | **Priority:** 🟡 IMPORTANT | **Exam Frequency:** 4/8 years

## Basic Knowledge: What is Feedback?

Feedback means taking a portion of an amplifier's output signal and sending it back to the input. We use a special feedback network to do this.

There are two main types of feedback:
1. **Positive Feedback:** The returned signal adds to the original input signal. This makes the total input bigger. The output gets even bigger. This creates a runaway loop. We use positive feedback to build oscillators.
2. **Negative Feedback:** The returned signal subtracts from the original input signal. This makes the total input smaller. The output gets smaller. This reduces the total voltage gain.

Why would we want to reduce our voltage gain? Because negative feedback gives us amazing benefits. It makes the amplifier extremely stable. It reduces distortion and noise. It widens the bandwidth. It also lets us change the input and output impedance to exactly what we need. 

Almost every practical amplifier uses negative feedback.

## How Do We Classify Feedback?

In negative feedback, we subtract a piece of the output signal from the input. But *how* we take that sample, and *how* we mix it back in, defines the type of circuit.

We have two choices at the output:
- We can sample the **Voltage**.
- We can sample the **Current**.

We have two choices at the input:
- We can mix it in **Series**.
- We can mix it in **Shunt (Parallel)**.

This gives us exactly four combinations. We call these the four feedback topologies.

## The Classification Matrix
*[Appeared in: 2024 Q3(a), 2022 Q2(c), 2017 Q4(a)]*

You must memorize this table. It answers almost every conceptual question about feedback topologies.

| Topology | Output Sampling | Input Mixing | Ideal Amplifier Type | Input Impedance ($Z_i$) | Output Impedance ($Z_o$) |
|---|---|---|---|:---:|:---:|
| **Voltage-Series** | Voltage (Parallel) | Series (Voltage) | Voltage Amp ($V_{out} / V_{in}$) | $\uparrow$ Increases | $\downarrow$ Decreases |
| **Voltage-Shunt** | Voltage (Parallel) | Shunt (Current) | Transresistance ($V_{out} / I_{in}$) | $\downarrow$ Decreases | $\downarrow$ Decreases |
| **Current-Series** | Current (Series) | Series (Voltage) | Transconductance ($I_{out} / V_{in}$) | $\uparrow$ Increases | $\uparrow$ Increases |
| **Current-Shunt** | Current (Series) | Shunt (Current) | Current Amp ($I_{out} / I_{in}$) | $\downarrow$ Decreases | $\uparrow$ Increases |

### The Golden Rules for Impedance

If you forget the exact table, just remember these two physical rules:

1. **Sampling at the Output:**
   - Sampling **Voltage** means connecting the feedback loop in parallel. Parallel connections pull resistance down. So, $Z_o$ **decreases**.
   - Sampling **Current** means connecting the feedback loop in series. Series connections add resistance. So, $Z_o$ **increases**.
2. **Mixing at the Input:**
   - Mixing in **Series** means injecting a voltage that fights the source. The source has to push harder. So, $Z_i$ **increases**.
   - Mixing in **Shunt** means injecting a current that bleeds away from the source. The source sees an easier path. So, $Z_i$ **decreases**.

## Deep Dive: Voltage-Shunt Feedback
*[Appeared in: 2017 Q4(a)]*

Exams occasionally ask you to explain one specific topology in detail. Let's look at the Voltage-Shunt topology.

**1. Output Sampling (Voltage):** 
The feedback network connects in parallel (shunt) with the load. It "reads" the output voltage. What happens physically? If the output voltage tries to spike up, the feedback network detects it. It tells the input to back off. This makes the output voltage incredibly stable. A stable voltage means the amplifier acts like an ideal voltage source. Ideal voltage sources have zero output impedance. Thus, the **output impedance decreases**.

$$
Z_{of} = \frac{Z_o}{1 + A\beta}
$$

**2. Input Mixing (Shunt):**
The feedback signal comes back and connects in parallel (shunt) with the input signal source. Instead of subtracting voltages, it subtracts currents. The feedback network injects a current ($I_f$) that opposes the input source current ($I_s$). 

Because the currents mix at a single node, the input voltage $V_i$ becomes very stable. If the source tries to push current in, the feedback loop immediately pulls it away. This makes it very easy for the source to deliver current. An easy path for current means low resistance. Thus, the **input impedance decreases**.

$$
Z_{if} = \frac{Z_i}{1 + A\beta}
$$

**3. Applications:**
The Voltage-Shunt topology has very low input impedance and very low output impedance. This makes it a terrible voltage amplifier. However, it makes a perfect **transresistance amplifier**. This is a circuit that converts an input current into an output voltage. The classic example is an inverting operational amplifier.

## ⚡ Exam Tips

- **Naming Convention Warning:** Sometimes exams flip the names. A "Voltage-Series" amplifier might be called a "Series-Shunt" amplifier (Input Mixing then Output Sampling). Always read carefully.
  - Series-Shunt = Voltage-Series
  - Shunt-Shunt = Voltage-Shunt
  - Series-Series = Current-Series
  - Shunt-Series = Current-Shunt
- **The Desensitivity Factor:** The term $(1 + A\beta)$ is the magic number. We call it the desensitivity factor. It divides the impedances that go down. It multiplies the impedances that go up.
