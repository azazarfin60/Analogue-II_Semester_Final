# Direct-Coupled Amplifier
> **Topic:** Multistage Amplifiers | **Priority:** 🟢 OCCASIONAL | **Exam Frequency:** 1/8 years

## Basic Knowledge: Blocking vs. Passing DC

In most amplifier circuits, we use capacitors to connect different stages together. We call these coupling capacitors. They do two things. First, they let the changing AC signal pass through to the next stage. Second, they block the steady DC voltage. This keeps the DC bias of one stage separate from the next stage.

But what if we need to amplify very slow signals? What if we need to amplify a steady DC voltage? Coupling capacitors act like high-pass filters. They block very low-frequency signals and DC completely. 

To solve this, we remove the coupling capacitors. We connect the output of the first stage directly to the input of the second stage. We call this a direct-coupled amplifier. It can amplify signals all the way down to 0 Hz (DC).

There is one big problem with this. Because there is no capacitor to block the DC, the bias voltage of the second stage depends entirely on the first stage. If the first stage drifts due to heat, the second stage will drift too. We call this DC drift. This is the main disadvantage of direct coupling.

## The Circuit Diagram

```
            V_CC
              |
         +----+---------+
         |    |         |
        [R1] [R_C1]    [R_C2]
         |    |         |
   Input |    +---------+----- Base (Q2) ← Direct Connection!
  ------>+   / Q1       |         (No capacitor)
         |--|        Q2 \
        [R2] \           |
         |    +          +---- Output (v_o)
         |   [R_E1]     [R_E2]
         |    |          |
        ===  ===        ===
        GND  GND        GND
```

Look at the connection between Q1 and Q2. The collector of Q1 connects straight to the base of Q2. There is no capacitor between them. 

Because of this direct link, the voltage at Q1's collector is exactly the same as the voltage at Q2's base:

$$
V_{B2} = V_{CC} - I_{C1} R_{C1}
$$

---

## Step-by-Step DC Analysis

We must find the bias conditions for both transistors. 

**Step 1: Bias the first stage (Q1)**

We use the voltage divider made by $R_1$ and $R_2$ to find the Thevenin voltage and resistance.

$$
R_{Th} = R_1 \| R_2, \quad E_{Th} = \frac{R_2}{R_1 + R_2} V_{CC}
$$

Now we calculate the base current for Q1:

$$
I_{B1} = \frac{E_{Th} - V_{BE1}}{R_{Th} + (\beta_1 + 1)R_{E1}}
$$

**Step 2: Find Q2's base voltage**

The base voltage of Q2 is tied directly to the collector of Q1. There is no separate voltage divider for Q2. 

$$
V_{B2} = V_{CC} - \beta_1 I_{B1} R_{C1}
$$

This equation is the most important part of direct coupling. The first stage entirely controls the second stage.

**Step 3: Find Q2's operating point**

Now we find the emitter voltage of Q2. We subtract the base-emitter drop:

$$
V_{E2} = V_{B2} - V_{BE2}
$$

Next, we calculate the emitter current for Q2:

$$
I_{E2} = \frac{V_{E2}}{R_{E2}}
$$

Finally, we find the collector-emitter voltage for Q2. If the collector connects directly to the power supply, then $V_{C2} = V_{CC}$.

$$
V_{CE2} = V_{C2} - V_{E2}
$$

---

## Phase Relationships

It helps to know how the signal phase changes through the stages. 

- A standard Common Emitter (CE) stage flips the signal upside down. This is a 180-degree phase shift.
- This rule applies to both NPN and PNP transistors in the CE configuration.

If you cascade two NPN stages, the signal flips twice. Two flips mean a 360-degree shift. The output will be exactly in-phase with the input.

---

## ⚡ Exam Tips

- Exams usually test direct coupling as theory. Know why we use it (to amplify DC and low frequencies). Know its main flaw (DC drift).
- Remember the key equation: $V_{B2} = V_{CC} - I_{C1}R_{C1}$. There is no Thevenin circuit for the second stage. The first stage sets the voltage directly.
