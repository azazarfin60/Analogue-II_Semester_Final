# Complementary Push-Pull Emitter Follower
> **Topic:** Multistage Amplifiers | **Priority:** 🟢 OCCASIONAL | **Exam Frequency:** 1/8 years

## Basic Knowledge: The Need for Push-Pull

Most simple amplifiers use a single transistor to drive the output. The problem is that a single transistor can only push current in one direction. It also wastes a lot of power. This is called Class A operation. It is not efficient for driving heavy loads like speakers.

To fix this, we use two transistors. We use one NPN transistor and one PNP transistor. We connect them in a mirror layout. We call this a complementary push-pull pair.

How does it work? An AC signal goes up and down. During the positive half of the signal, the top NPN transistor turns on. It "pushes" current from the power supply into the load. The PNP transistor stays off. 

During the negative half of the signal, the NPN turns off. The bottom PNP transistor turns on. It "pulls" current from the load to the ground. 

They take turns doing the work. This makes the amplifier very efficient. It can deliver large amounts of power without wasting energy. You will find this circuit at the output stage of almost every audio amplifier and op-amp.

       |    |  +--+
       |    |  | E

We take the output from the middle point between both emitters. The main design goal is to set the resting output voltage ($V_o$) at exactly half the supply voltage. Here, half of 18V is 9V.

## Step-by-Step DC Bias Analysis

**Goal:** Find all DC currents and voltages to make sure $V_o = 9\text{ V}$.

**Step 1: Q1 (NPN) Analysis**

The emitter of Q1 sits at $V_o = 9\text{ V}$. Its collector connects to $V_{CC}$ through resistor $R_C$. 

First, we find the voltage at the base of Q1. We add the base-emitter voltage drop:

$$
V_{B1} = V_o + V_{BE1} = 9 + 0.7 = 9.7\text{ V}
$$

Next, we calculate the current flowing through $R_C$:

$$
I_{RC} = \frac{V_{CC} - V_{B1}}{R_C} = \frac{18 - 9.7}{750} = \frac{8.3}{750} \approx 11.07\text{ mA}
$$

**Step 2: Q2 (PNP) Analysis**

Q2 is a PNP transistor. Its emitter connects to ground (0V). For a PNP transistor to turn on, its base voltage must be lower than its emitter voltage. It needs to be about 0.7V below the emitter.

But in this specific circuit, Q2's base gets biased through the 2 MΩ resistor network. Q2 only turns on during the negative half of the AC cycle. It conducts when the output signal swings below the resting $V_o$ level.

We calculate the small biasing current through the 2 MΩ resistor:

$$
I_{bias} = \frac{V_o}{R_S} = \frac{9}{2\text{M}} = 4.5\;\mu\text{A}
$$

This base current is very small. This makes sense because the transistors have high $\beta$ values.

## Key Feature Comparison

| Feature | Single Transistor (Class A) | Push-Pull Pair (Class B/AB) |
|---|---|---|
| **Conduction Time** | Works the entire time | Each works half the time |
| **Power Efficiency** | Maximum 25% | Up to 78.5% |
| **Crossover Distortion** | None | Yes (requires biasing) |
| **Power Delivery** | Low | Very High |

### The Crossover Distortion Problem

There is a small gap where the signal crosses zero. At this point, the input voltage is between -0.7V and +0.7V. Neither transistor has enough voltage to turn on. The output stays dead for a moment. This creates a flat spot in the wave. We call this crossover distortion.

We solve this problem by adding a small bias voltage to the bases. This bias keeps both transistors slightly turned on all the time. This eliminates the dead zone. We call this Class AB operation.

## ⚡ Exam Tips

- **Remember the roles.** NPN pushes current on the positive half. PNP pulls current on the negative half.
- **Midpoint voltage.** The resting output voltage should sit perfectly in the middle ($V_{CC}/2$). This allows the signal to swing up and down equally without clipping.
- **Know the distortion fix.** If they ask how to fix crossover distortion, tell them to bias both transistors slightly ON. Mention "Class AB".
