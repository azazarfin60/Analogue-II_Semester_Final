# Miller Capacitance Theorem
> **Topic:** Frequency Response | **Priority:** 🟡 IMPORTANT | **Exam Frequency:** 4/8 years

## Basic Knowledge: The Capacitor Illusion

In AC circuits, a capacitor passes alternating current. The amount of current it pulls depends on two things. First, the size of the capacitor. Second, the voltage changing across it. 

Imagine an inverting amplifier. It has a very high voltage gain. If the input goes up by 1V, the output might go down by 100V. 

Now, place a small feedback capacitor between the input and the output. When the input goes up by 1V, the other side of the capacitor goes down by 100V. The total voltage difference across the capacitor is 101V. 

Because the voltage difference is so huge, the small capacitor pulls a massive amount of current from the input. To the input signal source, it feels like it is driving a giant capacitor connected straight to ground. The small capacitor creates an illusion. It acts like a massive capacitor. We call this the **Miller Effect**. 

This giant virtual capacitance acts as a strong low-pass filter. It destroys the high-frequency bandwidth of the amplifier.

## What is Miller's Theorem?

**Miller's Theorem** gives us the math to explain this illusion. 

It states that any impedance ($Z_f$) connected between the input and output of an amplifier can be removed. Instead, you can replace it with two separate ground-connected (shunt) impedances. You place one at the input ($Z_{in(M)}$). You place the other at the output ($Z_{out(M)}$). This makes circuit analysis much easier.

## The Derivation: $C_{Mi}$ and $C_{Mo}$
*[Appeared in: 2024 Q4(a), 2022 Q2(a)]*

This derivation is a classic exam question. You must prove how a single feedback capacitor ($C_f$) transforms into the two Miller capacitances.

### The Setup

Imagine an amplifier with a voltage gain of $A_v$. We connect a feedback capacitor $C_f$ between the input node ($V_i$) and the output node ($V_o$).

```
               +------ C_f ------+
               |                 |
        V_i o---o-----[ A_v ]----o---o V_o
```

By definition of voltage gain:

$$
V_o = A_v \cdot V_i
$$

### Part 1: Proving the Input Miller Capacitance ($C_{Mi}$)

**Step 1: Calculate the true current through $C_f$.**
We find the current ($I_{in}$) flowing from the input to the output.

$$
I_{in} = \frac{V_i - V_o}{Z_f} = \frac{V_i - V_o}{1 / (j\omega C_f)} = j\omega C_f (V_i - V_o)
$$

**Step 2: Substitute $V_o$ with the gain equation.**
Since $V_o = A_v V_i$, we plug this into the current formula:

$$
I_{in} = j\omega C_f (V_i - A_v V_i) = j\omega C_f (1 - A_v) V_i
$$

**Step 3: Build the equivalent circuit.**
We want to replace $C_f$ with a new capacitor ($C_{Mi}$). We connect this new capacitor from the input straight to ground. It must draw the exact same current:

$$
I_{in} = \frac{V_i}{Z_{Mi}} = \frac{V_i}{1 / (j\omega C_{Mi})} = j\omega C_{Mi} V_i
$$

**Step 4: Solve for $C_{Mi}$.**
Set the two $I_{in}$ equations equal to each other:

$$
j\omega C_{Mi} V_i = j\omega C_f (1 - A_v) V_i
$$

Cancel the common term ($j\omega V_i$) on both sides:

$$
\boxed{ C_{Mi} = C_f (1 - A_v) }
$$

> **Key Rule:** If the amplifier is inverting, $A_v$ is negative (e.g., $A_v = -100$). The math becomes $C_{Mi} = C_f(1 - (-100)) = 101 C_f$. The small capacitor gets multiplied by the huge gain.

---

### Part 2: Proving the Output Miller Capacitance ($C_{Mo}$)

**Step 1: Calculate the reverse current.**
Let's find the current ($I_{out}$) flowing from the output back to the input:

$$
I_{out} = \frac{V_o - V_i}{Z_f} = j\omega C_f (V_o - V_i)
$$

**Step 2: Substitute $V_i$.**
Since $V_o = A_v V_i$, we can rewrite it as $V_i = V_o / A_v$. Plug this in:

$$
I_{out} = j\omega C_f \left( V_o - \frac{V_o}{A_v} \right) = j\omega C_f \left( 1 - \frac{1}{A_v} \right) V_o
$$

**Step 3: Build the equivalent circuit.**
We want to replace $C_f$ with a new capacitor ($C_{Mo}$). We connect it from the output straight to ground:

$$
I_{out} = j\omega C_{Mo} V_o
$$

**Step 4: Solve for $C_{Mo}$.**
Set the two $I_{out}$ equations equal:

$$
j\omega C_{Mo} V_o = j\omega C_f \left( 1 - \frac{1}{A_v} \right) V_o
$$

Cancel $j\omega V_o$ on both sides:

$$
\boxed{ C_{Mo} = C_f \left( 1 - \frac{1}{A_v} \right) }
$$

> **Key Rule:** If the gain is very large, then $1/A_v$ is basically zero. This means $C_{Mo} \approx C_f$. The output Miller capacitance is roughly equal to the original feedback capacitor.

## ⚡ Exam Tips

1. **Watch the negative sign.** If you do a numerical problem for a Common-Emitter amplifier, remember that $A_v$ is negative. The formula uses $(1 - A_v)$. Do not forget the double negative.
2. **The steps are simple algebra.** To remember the proof, start with Ohm's law. Write the equation for the current through the feedback capacitor. Then swap $V_o$ with $A_v V_i$. Finally, factor out the input voltage.
