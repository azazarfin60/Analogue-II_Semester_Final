# Schmitt Trigger and Hysteresis
> **Topic:** Op-Amp Applications | **Priority:** 🔴 CRITICAL | **Exam Frequency:** 5/8 years

## Basic Knowledge: The Comparator

A standard op-amp comparator does exactly what its name suggests. It compares two voltages. You put a reference voltage on one pin and an input signal on the other. 

Because the op-amp has massive open-loop gain, it cannot sit in the middle. If the input is even 1 mV higher than the reference, the output slams all the way up to the positive supply limit ($+V_{sat}$). If the input is 1 mV lower, the output slams all the way down to the negative supply limit ($-V_{sat}$). 

This turns a smooth analog wave into a sharp digital square wave.

---

## 1. The Problem: Comparator Chattering
*[Appeared in: 2019 Q4(c), 2018 Q4(c)]*

A standard comparator compares an input voltage against a single reference threshold line. 

**The Flaw:** Real-world analog signals are noisy. Imagine a slow-moving analog signal crossing your reference threshold. There are tiny, random noise spikes riding on top of that main signal. 

As the signal crosses the line, these noise spikes will cause the total voltage to cross back and forth across the exact threshold line dozens of times in a millisecond. 

This causes the op-amp output to violently switch back and forth between $+V_{sat}$ and $-V_{sat}$ multiple times before the main signal finally clears the threshold area. We call this **Chattering**. It is a massive problem because it destroys the digital logic circuits trying to read the output.

---

## 2. The Solution: Hysteresis via Schmitt Trigger

To fix chattering, we use a **Schmitt Trigger**. A Schmitt trigger is simply a comparator with **Positive Feedback**.

By feeding a fraction of the output voltage back to the non-inverting terminal, the circuit creates *two different threshold voltages* instead of one:
1. **Upper Trigger Point ($V_{UT}$):** The threshold the input must cross when it is rising.
2. **Lower Trigger Point ($V_{LT}$):** The threshold the input must cross when it is falling.

**How it stops chattering:**
Imagine the output is currently at $-V_{sat}$. The threshold is currently set at the Upper Trigger Point (for example, 7V). The noisy input rises and finally hits 7V. The output instantly snaps to $+V_{sat}$. 

Because of the positive feedback, the moment the output flips, the threshold *instantly drops* to the Lower Trigger Point (for example, 3V). 

Now, even if the noisy input wobbles around 6.9V, it does not matter at all. The threshold is now way down at 3V. The output stays completely stable at $+V_{sat}$. The input would have to drop all the way back down past 3V to make it switch back.

This memory effect is called **Hysteresis**. The threshold depends on the current output state. The hysteresis width is simply $V_{UT} - V_{LT}$.

## 3. Worked Schmitt Trigger Design
*[Appeared in: 2020 Q8(c)]*

This is a classic 6-mark design question.

**Problem Details:**
Design an inverting Schmitt trigger with an Upper Trigger Point $V_{UT} = 7\text{ V}$, and a Lower Trigger Point $V_{LT} = 3\text{ V}$. Assume the op-amp saturation voltages are $\pm 14\text{ V}$.

### Step 1: The Circuit Setup
An inverting Schmitt trigger applies the input $V_{in}$ to the inverting (-) terminal. 
The non-inverting (+) terminal connects to a voltage divider. This divider consists of a feedback resistor $R_F$ (coming from the output) and an input resistor $R_1$ (connected to a reference DC voltage $V_{ref}$).

### Step 2: The Threshold Equations
The voltage at the non-inverting terminal determines the threshold. We use the superposition principle with $V_{ref}$ and $V_{out}$:

$$
V_{threshold} = V_{ref} \left( \frac{R_F}{R_1 + R_F} \right) + V_{out} \left( \frac{R_1}{R_1 + R_F} \right)
$$

When $V_{out} = +V_{sat} (+14\text{V})$, the threshold is pulled up to $V_{UT}$:

$$
V_{UT} = V_{ref} \left( \frac{R_F}{R_1 + R_F} \right) + 14 \left( \frac{R_1}{R_1 + R_F} \right) = 7\text{ V} \quad \text{(Eq. 1)}
$$

When $V_{out} = -V_{sat} (-14\text{V})$, the threshold is pulled down to $V_{LT}$:

$$
V_{LT} = V_{ref} \left( \frac{R_F}{R_1 + R_F} \right) - 14 \left( \frac{R_1}{R_1 + R_F} \right) = 3\text{ V} \quad \text{(Eq. 2)}
$$

### Step 3: Solve for the Resistor Ratio
We want to eliminate $V_{ref}$ to find the ratio between $R_1$ and $R_F$. 
**Subtract** Eq. 2 from Eq. 1:

$$
14 \left( \frac{R_1}{R_1 + R_F} \right) - \left( -14 \left( \frac{R_1}{R_1 + R_F} \right) \right) = 7\text{ V} - 3\text{ V}
$$

$$
28 \left( \frac{R_1}{R_1 + R_F} \right) = 4
$$

$$
\frac{R_1}{R_1 + R_F} = \frac{4}{28} = \frac{1}{7}
$$

Cross-multiply to solve:

$$
7 R_1 = R_1 + R_F
$$

$$
\implies \mathbf{R_F = 6 R_1}
$$

*Design Choice:* Let's pick a standard value for $R_1$, say **$10\text{ k}\Omega$**.
Therefore, **$R_F = 60\text{ k}\Omega$**.

### Step 4: Solve for the Reference Voltage ($V_{ref}$)
Now that we know the ratio $\frac{R_F}{R_1 + R_F} = \frac{6R_1}{7R_1} = \frac{6}{7}$, we can plug it back in.
**Add** Eq. 1 and Eq. 2 to eliminate the 14V term:

$$
2 V_{ref} \left( \frac{R_F}{R_1 + R_F} \right) = 7\text{ V} + 3\text{ V} = 10\text{ V}
$$

$$
2 V_{ref} \left( \frac{6}{7} \right) = 10\text{ V}
$$

$$
V_{ref} \left( \frac{6}{7} \right) = 5\text{ V}
$$

$$
V_{ref} = 5 \times \frac{7}{6} = \frac{35}{6} \approx \mathbf{5.83\text{ V}}
$$

### Final Design
- Op-Amp inverting terminal: Connected to $V_{in}$
- Op-Amp non-inverting terminal: Connected to the resistor junction.
- $R_F = 60\text{ k}\Omega$ connects the non-inverting terminal to the Output.
- $R_1 = 10\text{ k}\Omega$ connects the non-inverting terminal to a DC supply of $+5.83\text{ V}$.

## ⚡ Exam Tips
- **The mathematical trick.** The trick to solving the design problem quickly is **Adding** the two equations to find $V_{ref}$, and **Subtracting** the two equations to find the resistor ratio.
- **Synonyms.** "Hysteresis" and "Schmitt Trigger" mean the exact same thing in exam questions. If they ask how to fix chattering, the answer is always adding positive feedback to create hysteresis.
