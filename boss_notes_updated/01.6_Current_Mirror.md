# Current Mirror and Wilson Current Mirror
> **Topic:** Multistage Amplifiers / IC Biasing | **Priority:** 🔴 CRITICAL | **Exam Frequency:** 6/8 years

## Basic Knowledge: The Need for Current Mirrors

Inside an integrated circuit (IC), resistors cause problems. They take up a massive amount of space on the silicon chip. A single 100 kΩ resistor can take up more space than 1000 transistors. IC designers want to avoid large resistors at all costs.

To solve this, designers use transistors to act like constant current sources. The current mirror is the most common way to do this. 

A current mirror creates a specific reference current on one side of the circuit. Then, it forces a second transistor to "mirror" or copy that exact same current on the other side. This provides a steady bias current without needing large resistors.

---

## Basic Two-Transistor Current Mirror

### The Circuit Diagram

```
                  +V_CC
                   |
                  [R]
                   |
        I_ref ----+------------+
                   |            |
                  Q1 (diode)   Q2 (mirror)
                   |            |
                  GND          GND → I_out (to load)
```

Notice the connection on Q1. The collector of Q1 connects directly to its base. This makes it a "diode-connected" transistor. It acts exactly like a regular diode. It conducts current in one direction and has a fixed voltage drop ($V_{BE}$).

### Step-by-Step Operation

**Step 1: Set the reference current.**
The resistor $R$ sets the main reference current ($I_{ref}$):

$$
I_{ref} = \frac{V_{CC} - V_{BE}}{R}
$$

**Step 2: Establish the base voltage.**
This reference current flows through Q1. It creates a specific base-emitter voltage ($V_{BE}$):

$$
V_{BE} = V_T \ln\left(\frac{I_{ref}}{I_S}\right)
$$

**Step 3: Share the voltage.**
Q1 and Q2 share the same base connection and the same emitter connection. Because of this, they share the exact same $V_{BE}$.

**Step 4: Mirror the current.**
If both transistors are identical, Q2 will conduct the exact same current as Q1:

$$
I_{out} = I_S \cdot e^{V_{BE}/V_T} = I_{ref}
$$

The output perfectly mirrors the reference. If you change $R$, the reference current changes. The output current follows immediately.

### The Beta Error

In the real world, the base current is not zero. Both Q1 and Q2 need some base current from the reference source.

$$
I_{ref} = I_{C1} + I_{B1} + I_{B2} = I_C + \frac{I_C}{\beta} + \frac{I_C}{\beta} = I_C\left(1 + \frac{2}{\beta}\right)
$$

We rearrange this to find the actual output current:

$$
\boxed{I_{out} = I_C = \frac{I_{ref}}{1 + 2/\beta}}
$$

**Common Exam Proof:**
The exam often asks you to prove that $I_{B1} = \frac{I_{control}}{\beta + 2}$.

Start at the common base node:
- The control current supplies both collectors and bases: $I_{control} = I_{C1} + I_{B1} + I_{B2}$.
- Since the transistors match, $I_{B1} = I_{B2}$. Also, $I_{C1} = \beta I_{B1}$.

$$
I_{control} = \beta I_{B1} + 2I_{B1} = (\beta + 2)I_{B1}
$$

$$
\boxed{I_{B1} = \frac{I_{control}}{\beta + 2}}
$$

If $\beta = 100$, the error is $\frac{2}{102} \approx 2\%$. This error is small but not perfect. High-precision circuits need something better.

### Built-in Self-Correction

The current mirror corrects itself through negative feedback. If the load current ($I_L$) tries to go up:

1. $I_{C2}$ goes up.
2. $I_{B2}$ goes up.
3. $V_{BE2}$ goes up.
4. $V_{BE1}$ goes up (they are connected).
5. $V_{CE1}$ goes up.
6. The control current goes down.
7. Total base current goes down.
8. $I_{B2}$ goes down.
9. $I_L$ goes back down.

The circuit fixes its own error automatically.

## Wilson Current Mirror (3-Transistor)

The Wilson current mirror uses three transistors. It reduces the base current error from $2/\beta$ down to $2/\beta^2$. This makes it much more accurate.

### The Circuit Diagram

```
                       I_out (to load)
                         |
                        Q3
                         |
           +-------------+-------+
           |                     |
          [R]                    |
           |                     |
        Iref ---> Q1 ----------- Q2
           |      |              |
           +------+              |
           |                     |
          GND                   GND
```

### How It Works

Q3 sits in series with the output. Its emitter current supplies the collector of Q2 and the bases of Q1 and Q2. 

If the output current tries to rise, Q2 conducts more current. This lowers the base voltage of Q3. The lower base voltage reduces Q3's collector current. This negative feedback keeps the output perfectly balanced.

### Mathematical Derivation

**Step 1:** Q1 and Q2 act as a basic mirror. So, $I_{C1} = I_{C2} = I_C$.

**Step 2:** The emitter current of Q3 feeds Q2's collector and both bases:

$$
I_{E3} = I_{C2} + I_{B1} + I_{B2} = I_C + \frac{2I_C}{\beta} = I_C\left(1 + \frac{2}{\beta}\right)
$$

**Step 3:** The output current is Q3's collector current:

$$
I_{out} = I_{C3} = \frac{\beta}{\beta+1} I_{E3} = \frac{\beta}{\beta+1} \cdot I_C\left(1 + \frac{2}{\beta}\right)
$$

$$
I_{out} = I_C \cdot \frac{\beta + 2}{\beta + 1}
$$

**Step 4:** We substitute and simplify the terms to get the final formula:

$$
\boxed{I_{out} = I_{ref} \cdot \frac{1}{1 + \frac{2}{\beta^2 + \beta}}}
$$

If $\beta = 100$, the error is $\frac{2}{10100} \approx 0.02\%$. This is 100 times better than the basic mirror.

---

### Worked Numerical: Wilson Current Mirror
*[2017 Q3(b)]*

**Given values:** $V_{CC} = 6\text{ V}$, $R = 1.3\text{ k}\Omega$, $\beta = 100$, $V_{BE} = 0.7\text{ V}$.

**Step 1: Find reference current.** 
The path goes through R, Q1's $V_{BE}$, and Q3's $V_{BE}$.

$$
I_{ref} = \frac{V_{CC} - V_{BE1} - V_{BE3}}{R} = \frac{6 - 0.7 - 0.7}{1.3\text{k}} = \frac{4.6}{1300} \approx 3.538\text{ mA}
$$

**Step 2: Find output current.**
First, find the error factor:

$$
\text{Error} = \frac{2}{\beta^2 + \beta} = \frac{2}{10100} \approx 0.000198
$$

Apply the error to the reference:

$$
I_{C3} = 3.538 \times \frac{1}{1.000198} \approx 3.537\text{ mA}
$$

**Step 3: Verify inner currents.** 
Current through Q2 = $I_{C2} \approx 3.537\text{ mA}$.
Current through Q3 = $3.537\text{ mA}$.

## ⚡ Exam Tips

1. **Check the denominator.** The proof formula has $\beta + 2$ on the bottom, not $\beta + 1$. This is because TWO transistors pull base current from the reference.
2. **Count the voltage drops.** The Wilson mirror has TWO $V_{BE}$ drops in the reference path. Do not forget this in your calculations: $I_{ref} = (V_{CC} - 2V_{BE})/R$.
3. **Know the purpose.** If asked to explain the function, say that it replaces resistors in ICs. It provides a steady bias current that perfectly mirrors a reference current.
