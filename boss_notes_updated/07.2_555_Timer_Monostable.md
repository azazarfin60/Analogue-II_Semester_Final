# 555 Timer: Monostable Mode and Applications
> **Topic:** 555 Timer | **Priority:** 🔴 CRITICAL | **Exam Frequency:** 6/8 years

## Basic Knowledge: The One-Shot Timer

The Astable mode runs continuously like a ticking clock. The **Monostable** mode is different. It is a "One-Shot" timer. 

It rests in a stable, quiet LOW state forever. It does absolutely nothing until it receives a sharp trigger signal. When it gets that trigger, it wakes up. It generates a single, precisely timed HIGH pulse. When the pulse finishes, it goes back to sleep and waits for the next trigger.

This is exactly how a microwave oven timer works. It sits at zero until you press "Start" (the trigger). It turns the microwave ON (HIGH pulse) for exactly 60 seconds. Then it turns back OFF and waits.

## 1. Monostable Mode Operation
*[Appeared in: 2020 Q6(a)]*

### The Circuit Wiring
We use only one resistor ($R$) connected from the power supply $V_{CC}$ directly to Pin 6 and 7. We use one capacitor ($C$) connected from Pin 6 and 7 down to ground. The input trigger signal goes into Pin 2.

### Proof of Pulse Width ($W \approx 1.1 RC$)
This is a standard 5-mark derivation.
When the trigger arrives at Pin 2, the internal discharge transistor turns OFF. The capacitor $C$ is now free to begin charging from 0V toward $V_{CC}$ through the resistor $R$. 
The standard equation for a charging capacitor is:

$$
v_c(t) = V_{CC} (1 - e^{-t / RC})
$$

The timer output stays HIGH until the capacitor voltage reaches the internal upper threshold ($2/3 V_{CC}$). Let the time it takes to reach this exact threshold be the pulse width, $W$.

$$
v_c(W) = \frac{2}{3} V_{CC}
$$

Substitute this into the standard charging equation:

$$
\frac{2}{3} V_{CC} = V_{CC} (1 - e^{-W / RC})
$$

Divide both sides by $V_{CC}$:

$$
\frac{2}{3} = 1 - e^{-W / RC}
$$

Rearrange the terms:

$$
e^{-W / RC} = 1 - \frac{2}{3} = \frac{1}{3}
$$

Take the natural logarithm ($\ln$) of both sides to cancel the exponential:

$$
-\frac{W}{RC} = \ln \left( \frac{1}{3} \right) = \ln(1) - \ln(3) = 0 - 1.0986
$$

$$
-\frac{W}{RC} = -1.0986
$$

Solve for $W$:

$$
\boxed{ W = 1.0986 RC \approx 1.1 RC }
$$

## 2. Worked Waveform Sketch
*[Appeared in: 2018 Q7(c)]*

**Problem Details:** Sketch the output voltage waveform ($V_o$) of a 555 monostable timer. It has $R = 4.7\text{ k}\Omega$ and $C = 0.1\ \mu\text{F}$. It is triggered by negative pulses at exactly $t = 1\text{ ms}$ and $t = 5\text{ ms}$.

**Step 1: Calculate the output pulse width ($W$)**

$$
W = 1.1 R C = 1.1 \times (4.7 \times 10^3) \times (0.1 \times 10^{-6}) \approx \mathbf{0.517\text{ ms}}
$$

**Step 2: Trace the Timeline**
- $t = 0 \to 1\text{ ms}$: The timer is resting. Output = 0V.
- **$t = 1\text{ ms}$:** The first trigger arrives! The output instantly snaps HIGH ($V_{CC}$).
- $t = 1.000 \to 1.517\text{ ms}$: The output remains HIGH while the capacitor charges up.
- **$t = 1.517\text{ ms}$:** The capacitor hits $2/3 V_{CC}$. The timer resets. The output snaps LOW (0V).
- $t = 1.517 \to 5\text{ ms}$: The timer is resting again. Output = 0V.
- **$t = 5\text{ ms}$:** The second trigger arrives! The output instantly snaps HIGH.
- **$t = 5.517\text{ ms}$:** The timer resets again. The output snaps LOW.

```text
       Vo
      HIGH+         +-----+                 +-----+
          |         |     |                 |     |
       LOW+---------+     +-----------------+     +---------
          0         1    1.517              5    5.517     t (ms)
```

## 3. Monostable Applications

### 3.1 Frequency Divider
*[Appeared in: 2021 Q7(b), 2019 Q7(b)]*

A monostable circuit can be used to divide the frequency of an incoming pulse train by 2, 3, or 4.
**How it works:** You set the RC time constant so the output pulse width $W$ is slightly longer than the incoming pulse period ($T_{in}$), but shorter than $2 T_{in}$.
- Trigger 1 arrives. The output goes HIGH for duration $W$.
- Trigger 2 arrives at time $T_{in}$. Because the timer is already active (the output is still HIGH), it completely ignores this second trigger!
- The output goes LOW at time $W$.
- Trigger 3 arrives at time $2 T_{in}$. The timer is resting again, so it triggers successfully.

By actively ignoring every second pulse, the output frequency is exactly halved: $f_{out} = f_{in} / 2$.

### 3.2 Missing Pulse Detector
*[Appeared in: 2020 Q6(c)]*

This is used in safety systems. It triggers an alarm if a heartbeat or engine pulse skips a beat.
**How it works:** A PNP transistor is connected across the timing capacitor $C$. The base of the transistor is driven directly by the incoming pulse train. 
- You set the pulse width $W$ to be slightly *longer* than the normal input period ($T_{in}$).
- Normally, every incoming pulse momentarily turns ON the transistor. This short-circuits the capacitor and resets its charge back to 0V. The capacitor never has enough time to reach $2/3 V_{CC}$. The output stays permanently HIGH.
- If a pulse goes missing, the transistor does not fire. The capacitor keeps charging. It finally hits $2/3 V_{CC}$. The output drops LOW and triggers the alarm.

### 3.3 Frequency Shift Keying (FSK) Modulator
*[Appeared in: 2019 Q8(a)]*

*(Note: FSK actually uses the Astable mode, but exams often group it in "Applications").*
**How it works:** A digital data stream of 0s and 1s is fed directly into **Pin 5 (Control Voltage)** of a free-running 555 astable oscillator.
- Pin 5 allows you to override the internal $2/3 V_{CC}$ reference.
- A Logic HIGH input raises the threshold above $2/3 V_{CC}$. The capacitor takes much longer to charge. This results in a **lower** output frequency.
- A Logic LOW input lowers the threshold below $2/3 V_{CC}$. The capacitor reaches the threshold very fast. This results in a **higher** output frequency.

The output actively shifts between two frequencies in perfect sync with the digital data.

## ⚡ Exam Tips
- **The RC Equation.** For the Pulse Width proof, you must know the standard RC charging equation ($1 - e^{-t/RC}$). The rest of the proof is just plugging in $2/3$ and using natural logs.
- **Draw clearly.** In waveform sketches, always draw the X-axis timeline clearly. Label the exact millisecond values where the pulses start and where they stop.
- **The Inequality.** For Frequency Dividers, the key mathematical inequality is $T_{in} < W < 2 T_{in}$. Write this down!
