## 🧭 Navigation

This repository is designed for use with **[Obsidian](https://obsidian.md/)** as a local knowledge vault, but is equally browsable on **GitHub** via standard Markdown links.

- Every directory contains an `index.md` file serving as a local table of contents.
- All Markdown files include **Previous / Home / Next** navigation headers and footers.
- Mathematical expressions use **LaTeX** syntax (`$...$` for inline, `$$...$$` for display blocks), compatible with both Obsidian's MathJax renderer and GitHub's math rendering.

### Quick Start
1. **Clone the repo** and open the root folder in Obsidian as a vault.
2. Start with [`Syllabus.md`](Syllabus.md) for the course outline.
3. Read [`analysis_report.md`](analysis_report.md) for exam strategy.
4. Dive into [`boss_notes/00-index.md`](boss_notes/00-index.md) for structured revision.
5. Practice with past papers in [`Prev.YearQuestions/`](Prev.YearQuestions/index.md) and check against [`answers/`](answers/index.md).

## 🔧 Tools & Scripts

### `download_transcripts.py`
A Python script for bulk-downloading and transcribing YouTube playlist lectures. Features:
- **yt-dlp** integration for audio extraction
- **faster-whisper** (GPU-accelerated) for local transcription and translation
- Automatic Hindi → English translation via Google Translate API fallback
- Deduplication (skips already-processed videos)
- Configurable model size (`tiny` → `large-v3`)

**Usage:**
```bash
python download_transcripts.py \
  --playlist "https://www.youtube.com/playlist?list=..." \
  --output-dir "raw_transcripts_output" \
  --whisper-model "large-v3" \
  --force-local True
```

**Requirements:** `yt-dlp`, `torch`, `faster-whisper`, `youtube-transcript-api`, `deep-translator`

## 📐 Course Syllabus Overview

### Part 1 — Amplifiers & Frequency Response
- Transistor types: BJT, FET, MOSFET
- Multistage amplifier circuits
- Frequency response of single-stage and multistage amplifiers
- Introduction to CMOS and its applications

### Part 2 — Advanced Analog Circuits & Systems
- Feedback amplifiers: classification, analysis, negative feedback
- Operational amplifiers: integrator, differentiator, compensation techniques
- Waveform generation: oscillators, multivibrators, 555 Timer
- Signal processing: active filters, negative impedance converters (NIC)

## 📌 Important Notes

> [!WARNING]
> **Known Gap:** The Sallen-Key 2nd-order active filter design (component value calculation) appeared in **4 out of 8 exams** but has only theoretical treatment in class notes — no worked numerical example. Study this from **Boylestad Ch. 15** or **Sedra/Smith**.
