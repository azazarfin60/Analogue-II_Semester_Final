# Voltage-Series Feedback Derivations
> **Topic:** Feedback Amplifiers | **Priority:** 🟡 IMPORTANT | **Exam Frequency:** 4/8 years

## The Magic Factor: $D = 1 + A\beta$

In all negative feedback calculations, you will see the term $(1 + A\beta)$ appear everywhere. This is called the **Desensitivity Factor** (often denoted as $D$). 

- $A$ is the open-loop gain (the raw gain of the amplifier with no feedback).
- $\beta$ is the feedback factor (the fraction of the output sent back to the input).
- $A\beta$ is the loop gain.

In a Voltage-Series feedback amplifier, negative feedback trades raw voltage gain for improved stability, wider bandwidth, higher input impedance, and lower output impedance. Every single one of these improvements is scaled by exactly the factor $D = 1 + A\beta$.

Exams frequently ask for the mathematical proof of these improvements. Let's walk through them.

---

## 1. Bandwidth Expansion Proof
*[Appeared in: 2024 Q3(b)]*

We need to prove that negative feedback pushes the upper cutoff frequency higher and the lower cutoff frequency lower, expanding the total bandwidth by $(1 + A\beta)$.

**Step 1: The Closed-Loop Gain Equation**
The fundamental equation for any negative feedback system is:

$$ A_f(f) = \frac{A(f)}{1 + A(f)\beta} $$

**Step 2: Upper Cutoff Frequency ($f_{Hf}$)**
We know the high-frequency response of the raw, open-loop amplifier falls off according to:

$$ A(f) = \frac{A_{mid}}{1 + j(f/f_H)} $$

Substitute this into the feedback equation:

$$ A_f(f) = \frac{ \frac{A_{mid}}{1 + j(f/f_H)} }{ 1 + \beta \left( \frac{A_{mid}}{1 + j(f/f_H)} \right) } $$

Multiply the top and bottom by $1 + j(f/f_H)$ to clear the fractions:

$$ A_f(f) = \frac{A_{mid}}{1 + j(f/f_H) + A_{mid}\beta} = \frac{A_{mid}}{(1 + A_{mid}\beta) + j(f/f_H)} $$

Now, divide the top and bottom by $(1 + A_{mid}\beta)$ to get it into standard form:

$$ A_f(f) = \frac{ \frac{A_{mid}}{1 + A_{mid}\beta} }{ 1 + j\left( \frac{f}{f_H (1 + A_{mid}\beta)} \right) } $$

Notice the denominator! The new upper cutoff frequency is clearly visible:

$$ \boxed{ f_{Hf} = f_H (1 + A_{mid}\beta) } $$
The upper cutoff moved *higher* by the factor $(1+A\beta)$.

**Step 3: Lower Cutoff Frequency ($f_{Lf}$)**
By doing the exact same math with the low-frequency response equation ($A(f) = \frac{A_{mid}}{1 - j(f_L/f)}$), we get:

$$ \boxed{ f_{Lf} = \frac{f_L}{1 + A_{mid}\beta} } $$
The lower cutoff moved *lower* by the factor $(1+A\beta)$.

**Step 4: Overall Bandwidth ($BW_f$)**
Bandwidth is $f_H - f_L$. Assuming $f_H \gg f_L$:

$$ BW_f \approx f_{Hf} = f_H (1 + A\beta) \approx \boxed{ BW_{open} \times (1 + A\beta) } $$

**Proof Complete!** Bandwidth has expanded.

---

## 2. Input Impedance ($Z_{if}$) Proof
*[Appeared in: 2021 Q2(b), 2018 Q6(a)]*

We need to prove that series input mixing increases the input impedance by $(1 + A\beta)$.

**Step 1: Define the voltages**
In a series connection, the feedback voltage ($V_f = \beta V_o$) is wired in series with the external source voltage ($V_s$). They oppose each other, so the actual voltage reaching the amplifier ($V_i$) is their difference:

$$ V_i = V_s - V_f = V_s - \beta V_o $$

**Step 2: Relate to the source voltage**
We know $V_o = A V_i$. Substitute this in:

$$ V_i = V_s - \beta (A V_i) $$

Rearrange to solve for the source voltage $V_s$:

$$ V_s = V_i + A\beta V_i = V_i(1 + A\beta) $$

**Step 3: Calculate Impedance**
By Ohm's law, the input impedance seen by the source is $Z_{if} = V_s / I_i$.
We also know the open-loop amplifier has an input impedance $Z_i = V_i / I_i$.

Substitute our equation for $V_s$ into the $Z_{if}$ equation:

$$ Z_{if} = \frac{V_i(1 + A\beta)}{I_i} $$

Since $V_i / I_i = Z_i$:

$$ \boxed{ Z_{if} = Z_i (1 + A\beta) } $$

**Proof Complete!** Input impedance increased.

---

## 3. Output Impedance ($Z_{of}$) Proof

We need to prove that parallel (shunt) output sampling decreases the output impedance by $(1 + A\beta)$.

**Step 1: The test voltage method**
To find output impedance mathematically, we turn off the input source ($V_s = 0$) and apply a fake "test voltage" ($V_t$) to the output terminal. The impedance will be $V_t$ divided by whatever current ($I_t$) gets drawn into the amplifier.

**Step 2: Calculate the current $I_t$**
The current flowing into the amplifier output is driven by the difference between our test voltage $V_t$ and the amplifier's internal dependent voltage source ($A V_i$), acting across the internal output resistance $Z_o$:

$$ I_t = \frac{V_t - A V_i}{Z_o} $$

**Step 3: What is $V_i$?**
Since the main source is off ($V_s = 0$), the only signal reaching the input is the feedback signal. The feedback network reads our test voltage $V_t$ and sends back $\beta V_t$.
Because it's negative feedback, $V_i = -V_f = -\beta V_t$.

**Step 4: Substitute and Solve**
Substitute $V_i = -\beta V_t$ into the current equation:

$$ I_t = \frac{V_t - A(-\beta V_t)}{Z_o} = \frac{V_t(1 + A\beta)}{Z_o} $$

Rearrange to find $Z_{of} = V_t / I_t$:

$$ \boxed{ Z_{of} = \frac{Z_o}{1 + A\beta} } $$

**Proof Complete!** Output impedance decreased.

## ⚡ Exam Tips

- **Read carefully:** Exams will often ask you to "prove that Voltage-Series feedback improves input and output resistance." This means you must do **both** derivation #2 and #3 above.
- The trick for the output impedance proof is remembering the "Test Voltage" method and setting $V_s = 0$. If you don't start with $V_s=0$, the math becomes an impossible mess.
