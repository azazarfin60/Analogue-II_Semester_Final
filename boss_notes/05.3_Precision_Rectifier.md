# Precision Rectifiers
> **Topic:** Op-Amp Applications | **Priority:** 🟡 IMPORTANT | **Exam Frequency:** 3/8 years

## Why Precision Rectifiers?

A standard silicon diode requires about $0.7\text{ V}$ of forward voltage to turn on. If you try to rectify a tiny $100\text{ mV}$ AC signal using a standard diode, nothing will happen — the signal isn't strong enough to open the gate.

To rectify very small signals (like those from medical sensors or audio equipment), we place the diode *inside* the feedback loop of an operational amplifier. The massive open-loop gain of the op-amp essentially divides the $0.7\text{ V}$ drop by $200,000$, turning it into a "Super Diode" that turns on at $0.000003\text{ V}$.

## 1. Precision Half-Wave Rectifier
*[Appeared in: 2020 Q7(c), 2019 Q5(b)]*

### The Circuit

```
                  D1 (Cathode)
              +----|<-----+
              |           |
        Vin o-(+)--[ Av ]-o----> Vout
              |           |
              +-----------+
```
*(Note: A load resistor $R_L$ is usually connected from $V_{out}$ to ground).*

### How it Works

**Case 1: Positive Half-Cycle ($V_{in} > 0$)**
1. The input voltage is slightly positive.
2. The op-amp amplifies this, swinging its output sharply positive.
3. This positive voltage forward-biases the diode $D_1$.
4. The diode conducts, **closing the feedback loop**.
5. With the loop closed, the circuit acts as a standard voltage follower. By virtual short, $V_- = V_+$, so the output voltage at the cathode perfectly tracks the input voltage.
   $$
   \boxed{ V_{out} = V_{in} }
   $$

**Case 2: Negative Half-Cycle ($V_{in} < 0$)**
1. The input voltage goes negative.
2. The op-amp swings its output sharply to negative saturation ($-V_{sat}$).
3. This massive negative voltage completely reverse-biases the diode $D_1$.
4. The diode turns OFF, **opening the feedback loop**.
5. With the loop broken, the op-amp is disconnected from the output node. The load resistor pulls the output node down to ground.
   $$
   \boxed{ V_{out} = 0\text{V} }
   $$

## 2. Precision Full-Wave Rectifier
*[Appeared in: 2023 Q8(a)]*

A full-wave precision rectifier (often called an Absolute Value Circuit) is built by cascading two stages: a half-wave rectifier and an inverting summer.

### The Logic
We want $V_{out} = |V_{in}|$.
- If $V_{in} = +5\text{V}$, we want $V_{out} = +5\text{V}$.
- If $V_{in} = -5\text{V}$, we want $V_{out} = +5\text{V}$.

### The Circuit Architecture
1. The input $V_{in}$ is fed into an **Inverting Summer** with a gain of $-1$.
2. The input $V_{in}$ is *also* fed into an **Inverting Half-Wave Rectifier**.
   - This special half-wave rectifier is designed to output $-V_{in}$ during positive cycles, and $0\text{V}$ during negative cycles.
3. The output of this half-wave rectifier is fed into the same Inverting Summer, but with a gain of $-2$.

### The Mathematical Proof

**During a Positive Cycle (e.g., $V_{in} = +5\text{V}$):**
- The half-wave rectifier outputs $-V_{in}$ ($-5\text{V}$).
- The summer receives the original $+5\text{V}$ (gain of $-1$) AND the rectifier's $-5\text{V}$ (gain of $-2$).
- Summer Output = $-(1 \times 5\text{V} + 2 \times -5\text{V}) = -(5 - 10) = -(-5) = \mathbf{+5\text{V}}$.

**During a Negative Cycle (e.g., $V_{in} = -5\text{V}$):**
- The half-wave rectifier is off, outputting $0\text{V}$.
- The summer receives the original $-5\text{V}$ (gain of $-1$) AND the rectifier's $0\text{V}$ (gain of $-2$).
- Summer Output = $-(1 \times -5\text{V} + 2 \times 0\text{V}) = -(-5 + 0) = \mathbf{+5\text{V}}$.

In both cases, the output is positive. The circuit successfully takes the absolute value!
