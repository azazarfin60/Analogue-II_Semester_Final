# Miller Capacitance Theorem
> **Topic:** Frequency Response | **Priority:** 🟡 IMPORTANT | **Exam Frequency:** 4/8 years

## What is Miller's Theorem?

Imagine an inverting amplifier with a very high voltage gain. If you accidentally (or intentionally) place a capacitor between the input and the output, a strange thing happens: from the perspective of the input, that capacitor looks *huge*. 

This is the **Miller Effect**. Because the output voltage is an inverted, amplified version of the input voltage, the voltage drop *across* the capacitor is massive. This pulls a huge amount of current from the input. To the input source, it feels like it's driving a much, much larger capacitor connected straight to ground.

**Miller's Theorem mathematically states:** An impedance $Z_f$ connected between the input and output terminals of an inverting amplifier (possessing a voltage gain $A_v$) can be replaced by two equivalent shunt impedances connected to ground: one at the input ($Z_{in(M)}$) and one at the output ($Z_{out(M)}$).

---

## The Derivation: $C_{Mi}$ and $C_{Mo}$
*[Appeared in: 2024 Q4(a), 2022 Q2(a)]*

This derivation is a classic exam question. It asks you to prove how a feedback capacitor $C_f$ transforms into the Miller input and output capacitances.

### The Setup

Imagine an amplifier with a voltage gain $A_v$. We connect a feedback capacitor $C_f$ between the input node ($V_i$) and output node ($V_o$).

```
               +------ C_f ------+
               |                 |
        V_i o---o-----[ A_v ]----o---o V_o
```

By definition of voltage gain:
$$
V_o = A_v \cdot V_i
$$

### Part 1: Proving the Input Miller Capacitance ($C_{Mi}$)

**Step 1: Calculate the actual current drawn by $C_f$ from the input.**
The current $I_{in}$ flowing through the feedback capacitor from left to right is:

$$
I_{in} = \frac{V_i - V_o}{Z_f} = \frac{V_i - V_o}{1 / (j\omega C_f)} = j\omega C_f (V_i - V_o)
$$

**Step 2: Substitute $V_o$.**
Since $V_o = A_v V_i$, plug this into the current equation:

$$
I_{in} = j\omega C_f (V_i - A_v V_i) = j\omega C_f (1 - A_v) V_i
$$

**Step 3: Equate to an equivalent shunt capacitor.**
We want to replace $C_f$ with an equivalent capacitor $C_{Mi}$ connected from the input straight to ground. This equivalent capacitor must draw the exact same current:

$$
I_{in} = \frac{V_i}{Z_{Mi}} = \frac{V_i}{1 / (j\omega C_{Mi})} = j\omega C_{Mi} V_i
$$

**Step 4: Solve for $C_{Mi}$.**
Set the two $I_{in}$ equations equal to each other:

$$
j\omega C_{Mi} V_i = j\omega C_f (1 - A_v) V_i
$$

Cancel the common terms ($j\omega V_i$):

$$
\boxed{ C_{Mi} = C_f (1 - A_v) }
$$

> **Note:** If it's an inverting amplifier, $A_v$ is negative (e.g., $A_v = -100$). The formula becomes $C_{Mi} = C_f(1 - (-100)) = 101 C_f$. The capacitance is multiplied by the gain!

---

### Part 2: Proving the Output Miller Capacitance ($C_{Mo}$)

**Step 1: Calculate the current flowing from the output back into $C_f$.**
Let's call this current $I_{out}$. It flows from $V_o$ to $V_i$:

$$
I_{out} = \frac{V_o - V_i}{Z_f} = j\omega C_f (V_o - V_i)
$$

**Step 2: Substitute $V_i$.**
Since $V_o = A_v V_i$, we can say $V_i = V_o / A_v$:

$$
I_{out} = j\omega C_f \left( V_o - \frac{V_o}{A_v} \right) = j\omega C_f \left( 1 - \frac{1}{A_v} \right) V_o
$$

**Step 3: Equate to an equivalent shunt capacitor.**
We want to replace $C_f$ with an equivalent capacitor $C_{Mo}$ connected from the output straight to ground:

$$
I_{out} = j\omega C_{Mo} V_o
$$

**Step 4: Solve for $C_{Mo}$.**
Set the two $I_{out}$ equations equal:

$$
j\omega C_{Mo} V_o = j\omega C_f \left( 1 - \frac{1}{A_v} \right) V_o
$$

Cancel $j\omega V_o$:

$$
\boxed{ C_{Mo} = C_f \left( 1 - \frac{1}{A_v} \right) }
$$

> **Note:** If the gain is very large ($|A_v| \gg 1$), then $1/A_v \approx 0$, which means $C_{Mo} \approx C_f$. The output Miller capacitance is basically just the feedback capacitance itself.

## ⚡ Exam Tips

1. **Don't forget the negative sign on $A_v$** if you are doing a numerical problem for a Common-Emitter or Common-Source amplifier. The formula has $(1-A_v)$. If $A_v$ is $-50$, the multiplier is $(1 - (-50)) = 51$.
2. The derivation is simple algebra. Just remember the starting point: write the equation for the current $I_{in}$ through the feedback component, substitute $V_o = A_v V_i$, and factor out $V_i$.
