# The Four Feedback Topologies
> **Topic:** Feedback Amplifiers | **Priority:** 🟡 IMPORTANT | **Exam Frequency:** 4/8 years

## How Do We Classify Feedback?

In negative feedback, we take a piece of the output signal and send it back to the input to subtract from the source signal. But *how* we take that sample, and *how* we subtract it, defines the type of feedback circuit.

There are only two things we can sample at the output: **Voltage** or **Current**.
There are only two ways we can mix it at the input: in **Series** or in **Shunt (Parallel)**.

This gives us exactly four combinations, known as the four feedback topologies.

---

## The Classification Matrix
*[Appeared in: 2024 Q3(a), 2022 Q2(c), 2017 Q4(a)]*

Memorize this table. It answers almost every conceptual question about feedback topologies.

| Topology | Output Sampling | Input Mixing | Ideal Amplifier Type | Input Impedance ($Z_i$) | Output Impedance ($Z_o$) |
|---|---|---|---|:---:|:---:|
| **Voltage-Series** | Voltage (Parallel) | Series (Voltage) | Voltage Amp ($V_{out} / V_{in}$) | $\uparrow$ Increases | $\downarrow$ Decreases |
| **Voltage-Shunt** | Voltage (Parallel) | Shunt (Current) | Transresistance ($V_{out} / I_{in}$) | $\downarrow$ Decreases | $\downarrow$ Decreases |
| **Current-Series** | Current (Series) | Series (Voltage) | Transconductance ($I_{out} / V_{in}$) | $\uparrow$ Increases | $\uparrow$ Increases |
| **Current-Shunt** | Current (Series) | Shunt (Current) | Current Amp ($I_{out} / I_{in}$) | $\downarrow$ Decreases | $\uparrow$ Increases |

### The Golden Rules for Impedance
If you forget the table, just remember these two physical rules:
1. **Sampling at the Output:**
   - Sampling **Voltage** means connecting the feedback loop in parallel. Parallel connections pull resistance down. $\to Z_o$ **decreases**.
   - Sampling **Current** means connecting the feedback loop in series. Series connections add resistance. $\to Z_o$ **increases**.
2. **Mixing at the Input:**
   - Mixing in **Series** means injecting a voltage that opposes the source. The source has to push harder. $\to Z_i$ **increases**.
   - Mixing in **Shunt** means injecting a current that bleeds away from the source. The source sees an easier path. $\to Z_i$ **decreases**.

## Deep Dive: Voltage-Shunt Feedback
*[Appeared in: 2017 Q4(a)]*

Exams occasionally ask you to explain one specific topology in detail. Let's look at Voltage-Shunt.

**1. Output Sampling (Voltage):** 
The feedback network is connected in parallel (shunt) with the load. It "reads" the output voltage. What happens physically? If the output voltage tries to spike due to noise or a changing load, the feedback network detects it and tells the input to back off. This makes the output voltage incredibly stable. A stable voltage regardless of current draw means the amplifier acts like an ideal voltage source. Ideal voltage sources have zero output impedance. Thus, **output impedance decreases**.

$$
Z_{of} = \frac{Z_o}{1 + A\beta}
$$

**2. Input Mixing (Shunt):**
The feedback signal is brought back and connected in parallel (shunt) with the input signal source. Instead of subtracting voltages, it subtracts *currents*. The feedback network injects a current ($I_f$) that opposes the input source current ($I_s$). 
Because currents are mixing at a single node, the input voltage $V_i$ is stabilized. If the source tries to push current in, the feedback loop immediately pulls it away, making it very easy for the source to deliver current but very hard to change the node voltage. An easy path for current means low resistance. Thus, **input impedance decreases**.

$$
Z_{if} = \frac{Z_i}{1 + A\beta}
$$

**3. Applications:**
Because Voltage-Shunt feedback has very low input impedance and very low output impedance, it makes a terrible voltage amplifier. However, it makes a perfect **transresistance amplifier** (a circuit that converts an input current into an output voltage). The classic example is an inverting operational amplifier configuration.

## ⚡ Exam Tips

- **Naming Convention Warning:** Sometimes exams flip the names! A "Voltage-Series" amplifier might be called a "Series-Shunt" amplifier (Input Mixing - Output Sampling). Always read carefully.
  - Series-Shunt = Voltage-Series
  - Shunt-Shunt = Voltage-Shunt
  - Series-Series = Current-Series
  - Shunt-Series = Current-Shunt
- Desensitivity factor ($D = 1 + A\beta$) is the magic number. It divides impedances that go down, and multiplies impedances that go up.
