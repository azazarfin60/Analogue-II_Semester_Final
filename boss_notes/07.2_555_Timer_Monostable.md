# 555 Timer: Monostable Mode & Applications
> **Topic:** 555 Timer | **Priority:** 🔴 CRITICAL | **Exam Frequency:** 6/8 years

## 1. Monostable (One-Shot) Mode
*[Appeared in: 2020 Q6(a)]*

While the Astable mode runs continuously, the Monostable mode rests in a stable LOW state forever. It only wakes up and generates a single, precisely timed HIGH pulse when it receives a negative trigger on Pin 2.

### The Circuit
We use only one resistor ($R$) connected from $V_{CC}$ to Pin 6/7. We use one capacitor ($C$) connected from Pin 6/7 to ground. The trigger input is Pin 2.

### Proof of Pulse Width ($W \approx 1.1 RC$)
This is a standard 5-mark derivation.
When triggered, the internal discharge transistor turns OFF. The capacitor $C$ begins charging from $0\text{V}$ toward $V_{CC}$ through $R$. 
The standard equation for a charging capacitor is:
$$
v_c(t) = V_{CC} (1 - e^{-t / RC})
$$

The output stays HIGH until the capacitor voltage reaches the internal upper threshold ($2/3 V_{CC}$). Let the time it takes to reach this threshold be the pulse width, $W$.
$$
v_c(W) = \frac{2}{3} V_{CC}
$$

Substitute this into the charging equation:
$$
\frac{2}{3} V_{CC} = V_{CC} (1 - e^{-W / RC})
$$
$$
\frac{2}{3} = 1 - e^{-W / RC}
$$
$$
e^{-W / RC} = 1 - \frac{2}{3} = \frac{1}{3}
$$

Take the natural logarithm ($\ln$) of both sides:
$$
-\frac{W}{RC} = \ln \left( \frac{1}{3} \right) = \ln(1) - \ln(3) = 0 - 1.0986
$$
$$
-\frac{W}{RC} = -1.0986
$$
$$
\boxed{ W = 1.0986 RC \approx 1.1 RC }
$$

## 2. Worked Waveform Sketch
*[Appeared in: 2018 Q7(c)]*

**Problem Details:** Sketch the output voltage waveform ($V_o$) of a 555 monostable timer with $R = 4.7\text{ k}\Omega$ and $C = 0.1\ \mu\text{F}$, if it is triggered by negative pulses at $t = 1\text{ ms}$ and $t = 5\text{ ms}$.

**Step 1: Calculate the output pulse width ($W$)**
$$
W = 1.1 R C = 1.1 \times (4.7 \times 10^3) \times (0.1 \times 10^{-6}) \approx \mathbf{0.517\text{ ms}}
$$

**Step 2: Trace the Timeline**
- $t = 0 \to 1\text{ ms}$: Timer is resting. Output = $0\text{V}$.
- **$t = 1\text{ ms}$:** Trigger arrives! Output instantly snaps HIGH ($V_{CC}$).
- $t = 1.000 \to 1.517\text{ ms}$: Output remains HIGH while capacitor charges.
- **$t = 1.517\text{ ms}$:** Capacitor hits $2/3 V_{CC}$. Timer resets. Output snaps LOW ($0\text{V}$).
- $t = 1.517 \to 5\text{ ms}$: Timer is resting. Output = $0\text{V}$.
- **$t = 5\text{ ms}$:** Second trigger arrives! Output snaps HIGH.
- **$t = 5.517\text{ ms}$:** Timer resets. Output snaps LOW.

```
       Vo
      HIGH+         +-----+                 +-----+
          |         |     |                 |     |
       LOW+---------+     +-----------------+     +---------
          0         1    1.517              5    5.517     t (ms)
```

## 3. Monostable Applications

### 3.1 Frequency Divider
*[Appeared in: 2021 Q7(b), 2019 Q7(b)]*
A monostable circuit can be used to divide the frequency of an incoming pulse train by 2, 3, 4, etc.
**How it works:** Set the RC time constant so the output pulse width $W$ is slightly longer than the incoming pulse period ($T_{in}$), but shorter than $2 T_{in}$.
- Trigger 1 arrives $\to$ Output goes HIGH for duration $W$.
- Trigger 2 arrives at $T_{in}$ $\to$ Because the timer is already active (output is still HIGH), it completely ignores this trigger!
- Output goes LOW at $W$.
- Trigger 3 arrives at $2 T_{in}$ $\to$ The timer is resting again, so it triggers successfully.
By ignoring every second pulse, the output frequency is exactly halved: $f_{out} = f_{in} / 2$.

### 3.2 Missing Pulse Detector
*[Appeared in: 2020 Q6(c)]*
Used in safety systems to trigger an alarm if a heartbeat or engine pulse skips a beat.
**How it works:** A PNP transistor is connected across the timing capacitor $C$. The base of the transistor is driven by the incoming pulse train. 
- Set the pulse width $W$ to be slightly *longer* than the normal input period ($T_{in}$).
- Normally, every incoming pulse momentarily turns ON the transistor, short-circuiting the capacitor and resetting its charge to $0\text{V}$. The capacitor never reaches $2/3 V_{CC}$, so the output stays permanently HIGH.
- If a pulse goes missing, the transistor doesn't fire. The capacitor keeps charging, hits $2/3 V_{CC}$, and the output drops LOW — triggering the alarm.

### 3.3 Frequency Shift Keying (FSK) Modulator
*[Appeared in: 2019 Q8(a)]*
*(Note: FSK uses the Astable mode, not Monostable, but is often grouped in "Applications").*
**How it works:** A digital data stream (0s and 1s) is fed into **Pin 5 (Control Voltage)** of a 555 astable oscillator.
- Pin 5 overrides the internal $2/3 V_{CC}$ reference.
- A Logic HIGH input raises the threshold above $2/3 V_{CC}$. The capacitor takes longer to charge, resulting in a **lower** output frequency.
- A Logic LOW input lowers the threshold below $2/3 V_{CC}$. The capacitor reaches the threshold faster, resulting in a **higher** output frequency.
The output shifts frequencies in sync with the digital data.

## ⚡ Exam Tips
- For the Pulse Width proof, you must know the standard RC charging equation ($1 - e^{-t/RC}$). The rest is just plugging in $2/3$ and using natural logs.
- In waveform sketches, always draw the $X$-axis timeline clearly and label the exact millisecond values where the pulses start and stop.
- For Frequency Dividers, the key inequality is $T_{in} < W < 2 T_{in}$. Write this down!
