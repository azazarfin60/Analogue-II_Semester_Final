# Complementary Push-Pull Emitter Follower
> **Topic:** Multistage Amplifiers | **Priority:** 🟢 OCCASIONAL | **Exam Frequency:** 1/8 years

## The Concept

The complementary push-pull configuration uses one NPN and one PNP transistor connected in a mirror arrangement. During the positive half-cycle of the input signal, the NPN transistor "pushes" current into the load. During the negative half-cycle, the PNP transistor "pulls" current from the load. Together, they can deliver large AC signals to a load with high efficiency.

This is the output stage of almost every audio amplifier and most op-amps.

---

## The Circuit
*[2024 Q.1(c)]*

```
            V_CC = +18V
              |
             [R_C] = 750Ω
              |
              +----+
              |    |
            C |    |
            --+    |
          B |  ----+ Q1 (NPN, β₁ = 140)
       +----+  | /|
       |    |  |/ |
       |    |  +--+ ← V_o (midpoint)
       |    |  |
       |    |  +-\
       |    |  |  \
      [ ]   |  |   ----+ Q2 (PNP, β₂ = 180)
      2MΩ   | B|   /|
       |    |  |  / |
       |    |  +--+
       |    |  | E
       +----+--+---------- GND
```

The output is taken from the common emitter junction of both transistors. The design goal: set the quiescent output voltage at exactly half the supply ($V_o = V_{CC}/2 = 9\text{ V}$).

---

## DC Bias Analysis

**Goal:** Find all DC currents and voltages such that $V_o = 9\text{ V}$.

**Step 1: Q1 (NPN) Analysis**

Q1's emitter is at $V_o = 9\text{ V}$, its collector connects to $V_{CC}$ through $R_C$:

$$
V_{B1} = V_o + V_{BE1} = 9 + 0.7 = 9.7\text{ V}
$$

The current through $R_C$:

$$
I_{RC} = \frac{V_{CC} - V_{B1}}{R_C} = \frac{18 - 9.7}{750} = \frac{8.3}{750} \approx 11.07\text{ mA}
$$

**Step 2: Q2 (PNP) Analysis**

Q2 is a PNP transistor with its emitter connected to ground ($0\text{V}$). For a PNP to turn ON, its base must be approximately $0.7\text{V}$ below its emitter, i.e., $V_{B2} \approx -0.7\text{V}$. However, in this particular circuit, Q2's base is biased through a separate path (the $2\text{ M}\Omega$ resistor network), and Q2 only conducts during the negative half-cycle of the AC signal when the output swings below $V_o$.

The biasing current through the $2\text{ M}\Omega$ resistor:

$$
I_{bias} = \frac{V_o}{R_S} = \frac{9}{2\text{M}} = 4.5\;\mu\text{A}
$$

This is a very small base current — appropriate for the high-$\beta$ transistors.

---

## Key Takeaway: Why Push-Pull?

| Feature | Single Transistor | Push-Pull Pair |
|---|---|---|
| **Conduction** | Only one half-cycle | Full cycle |
| **Efficiency** | ~25% (Class A) | Up to 78.5% (Class B) |
| **Crossover Distortion** | None | Present (needs biasing) |
| **Power Delivery** | Limited | High |

The crossover distortion problem (where neither transistor conducts near the zero-crossing) is solved by adding a small forward bias to keep both transistors slightly ON at all times — this is "Class AB" operation.

## ⚡ Exam Tips

- Remember: NPN conducts on positive half-cycles, PNP on negative half-cycles.
- The output sits at $V_{CC}/2$ for symmetrical clipping.
- If they ask about "crossover distortion," the fix is to bias both transistors slightly ON (Class AB).
