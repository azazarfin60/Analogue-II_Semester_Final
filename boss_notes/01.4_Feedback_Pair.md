# Feedback Pair (Complementary Darlington)
> **Topic:** Multistage Amplifiers | **Priority:** 🟢 OCCASIONAL | **Exam Frequency:** 2/8 years

## What Makes This Different from a Darlington?

The Darlington pair uses two transistors of the **same type** (both NPN or both PNP). The Feedback Pair uses **complementary** transistors — typically a PNP followed by an NPN. This creates interesting differences in the current path and the biasing equations.

The name "feedback pair" comes from the fact that the collector of Q2 (NPN) feeds back to the emitter of Q1 (PNP), creating a natural feedback loop that makes the circuit more stable.

---

## The Circuit

```
             V_CC
              |
         +----+-------+
         |            |
        [R_B]        [R_C]
         |            |
    C_s  |            +-----+----- V_o
   --||--+            |     |
         |        Q1 (PNP)  |
         |         /|       |
         +----- B-| Q1      |
                   \|        |
                    +--C1----+-- B(Q2)
                    |E1      |
                    |     Q2 (NPN)
                    |      |\
                    |   C2-| Q2
                    |      |/
                   ===      +--E2
                   GND      |
                           ===
                           GND
```

**Key connections:**
- Q1 is PNP — its emitter is at $V_{CC}$, collector goes down
- Q2 is NPN — its collector feeds back to the same $R_C$ path
- The collector of Q1 drives the base of Q2
- $I_{B2} = I_{C1}$ — Q1's collector current is Q2's base current

---

## DC Analysis

The current relationships are similar in spirit to the Darlington, but the current flow is different because Q1 is PNP:

$$I_{C1} = \beta_1 I_{B1}$$

$$I_{B2} = I_{C1} = \beta_1 I_{B1}$$

$$I_{C2} = \beta_2 I_{B2} = \beta_1 \beta_2 I_{B1}$$

The total current through $R_C$ includes both Q1's emitter current and Q2's collector current:

$$I_C = I_{E1} + I_{C2} = (\beta_1 + 1)I_{B1} + \beta_1\beta_2 I_{B1}$$

$$I_C = I_{B1}(\beta_1 + 1 + \beta_1\beta_2)$$

Since $\beta_1\beta_2 \gg \beta_1 + 1$:

$$I_C \approx \beta_1\beta_2 I_{B1}$$

**KVL to find $I_{B1}$:**

$$V_{CC} - I_C R_C - V_{BE1} - I_{B1} R_B = 0$$

$$V_{CC} - (\beta_1\beta_2 I_{B1}) R_C - V_{BE1} - I_{B1} R_B = 0$$

$$I_{B1} = \frac{V_{CC} - V_{BE1}}{R_B + \beta_1\beta_2 R_C}$$

**DC Voltages:**

$$V_{B1} = I_{B1} \cdot R_B$$

$$V_{C1} = V_{BE2} = 0.7\text{ V}$$

$$V_{C2} = V_{CC} - I_C R_C$$

## Key Differences: Darlington vs Feedback Pair

| Feature | Darlington | Feedback Pair |
|---|---|---|
| **Transistor Types** | Same (NPN-NPN or PNP-PNP) | Complementary (PNP-NPN) |
| **$V_{BE}$ Drop** | $2V_{BE} = 1.4\text{ V}$ | Only $1V_{BE} = 0.7\text{ V}$ at base |
| **Current Gain** | $\beta_D \approx \beta_1\beta_2$ | Same: $\approx \beta_1\beta_2$ |
| **$I_{B1}$ Formula** | $\frac{V_{CC} - 2V_{BE}}{R_B + \beta_D R_E}$ | $\frac{V_{CC} - V_{BE}}{R_B + \beta_1\beta_2 R_C}$ |
| **Built-in Feedback** | No | Yes (inherently more stable) |

## ⚡ Exam Tips

- The feedback pair formula has $R_C$ (not $R_E$) in the denominator because the total current flows through $R_C$, not through a separate emitter resistor.
- Only ONE $V_{BE}$ appears in the $I_{B1}$ formula (Q1's PNP $V_{BE}$), unlike the Darlington's two $V_{BE}$ drops.
