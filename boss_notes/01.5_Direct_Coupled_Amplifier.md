# Direct-Coupled Amplifier
> **Topic:** Multistage Amplifiers | **Priority:** 🟢 OCCASIONAL | **Exam Frequency:** 1/8 years

## What is Direct Coupling?

In most multistage amplifiers, stages are connected through coupling capacitors that block DC but pass AC signals. In a **direct-coupled** amplifier, there are NO coupling capacitors — the collector of one stage is connected *directly* to the base of the next stage.

Why would you do this? Because coupling capacitors act as high-pass filters — they block very low-frequency signals. If you need to amplify signals down to DC (0 Hz), you have no choice but to direct-couple the stages.

The downside: since DC passes through, the bias point of Stage 2 depends entirely on the output voltage of Stage 1. Any drift in Stage 1's bias (due to temperature, etc.) directly affects Stage 2. This is called **DC drift** — the biggest problem with direct-coupled amplifiers.

## The Circuit

```
            V_CC
              |
         +----+---------+
         |    |         |
        [R1] [R_C1]    [R_C2]
         |    |         |
   Input |    +---------+----- Base (Q2) ← Direct Connection!
  ------>+   / Q1       |         (No capacitor)
         |--|        Q2 \
        [R2] \           |
         |    +          +---- Output (v_o)
         |   [R_E1]     [R_E2]
         |    |          |
        ===  ===        ===
        GND  GND        GND
```

The critical connection: the **collector of Q1** connects directly to the **base of Q2** without any capacitor. This means:

$$V_{B2} = V_{CC} - I_{C1} R_{C1}$$

---

## DC Analysis

**Step 1: Bias Q1 using the voltage divider:**

$$R_{Th} = R_1 \| R_2, \quad E_{Th} = \frac{R_2}{R_1 + R_2} V_{CC}$$

$$I_{B1} = \frac{E_{Th} - V_{BE1}}{R_{Th} + (\beta_1 + 1)R_{E1}}$$

**Step 2: Find Q2's base voltage (the direct coupling point):**

$$V_{B2} = V_{CC} - \beta_1 I_{B1} R_{C1}$$

This is the voltage at Q1's collector — and since there's no coupling capacitor, it IS Q2's base voltage.

**Step 3: Find Q2's operating point:**

$$V_{E2} = V_{B2} - V_{BE2}$$

$$I_{E2} = \frac{V_{E2}}{R_{E2}}$$

$$V_{C2} = V_{CC} \quad (\text{if collector goes directly to supply})$$

$$V_{CE2} = V_{C2} - V_{E2}$$

---

## Phase Relationships in Direct-Coupled Stages

A key conceptual point often tested:

- **NPN CE Stage** → inverts the signal ($180°$ phase shift)
- **PNP CE Stage** → also inverts the signal ($180°$ phase shift)

If both stages are NPN: Output has $360° = 0°$ phase shift (in-phase with input).

In a direct-coupled amplifier using NPN-PNP complementary stages, careful biasing is needed since the PNP transistor requires a different voltage polarity at its base.

---

## ⚡ Exam Tips

- Direct coupling is mainly asked as a conceptual/theory question — understand *why* it's used (DC amplification, no frequency cutoff) and its disadvantage (DC drift).
- The key calculation difference: $V_{B2} = V_{CC} - I_{C1}R_{C1}$ — there's no Thevenin equivalent for Stage 2's base, it's directly set by Stage 1.
