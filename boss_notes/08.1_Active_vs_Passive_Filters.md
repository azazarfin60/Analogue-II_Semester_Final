# Active vs. Passive Filters
> **Topic:** Active Filters | **Priority:** 🔴 CRITICAL | **Exam Frequency:** 5/8 years

## 1. What is an Active Filter?
*[Appeared in: 2024 Q6(a), 2020 Q4(a), 2021 Q3(a)]*

A passive filter is built exclusively using passive components (Resistors, Capacitors, Inductors).
An **Active Filter** incorporates an active amplifier element (like an Operational Amplifier) into the RC network. 

Because op-amps can simulate the mathematical effects of inductance using only resistors and capacitors, active filters completely eliminate the need for physical inductors, which are heavy, lossy, and expensive.

### Comparison Matrix
This is a guaranteed 3-4 mark theoretical question.

| Parameter | Active Filters | Passive Filters |
|---|---|---|
| **Gain** | Can provide voltage gain (passband gain $> 1$). | Cannot amplify. Always exhibits some attenuation ($< 1$). |
| **Inductors** | **No inductors required.** Uses op-amps, Rs, and Cs. | **Requires inductors** (bulky, high resistance, magnetic interference). |
| **Loading Effect** | No loading effect. High input impedance, low output impedance. Stages can be cascaded freely. | Severe loading effect. Connecting stages alters their cutoff frequencies. |
| **Power Supply** | Requires external DC power ($+V_{CC}, -V_{EE}$) for op-amps. | Requires no external power (self-powered). |
| **Frequency Range** | Limited to lower frequencies ($< 1\text{ MHz}$) by the op-amp's bandwidth. | Excellent for high frequencies (RF/Microwave). |

## 2. Standard Filter Responses
*[Appeared in: 2024 Q6(b)]*

When designing a filter, you have to choose a mathematical polynomial to approximate the "ideal" brick-wall response. The three most common approximations asked in exams are:

1. **Butterworth Filter:** 
   - **Advantage:** Maximally flat passband (absolutely no ripples).
   - **Disadvantage:** Slower roll-off in the transition region.
   - **Use Case:** Audio processing where you want perfect, undistorted gain across the entire passband.
2. **Chebyshev Filter:**
   - **Advantage:** Extremely steep roll-off.
   - **Disadvantage:** Introduces noticeable amplitude ripples in the passband (Type I) or stopband (Type II).
   - **Use Case:** Radio transmitters where you must strictly eliminate an adjacent frequency channel, even if it slightly distorts the main signal.
3. **Bessel Filter:**
   - **Advantage:** Linear phase response (constant time delay for all frequencies).
   - **Disadvantage:** Slowest roll-off rate of all three.
   - **Use Case:** Digital data transmission where phase distortion would ruin the shape of a square wave pulse.

## 3. Third-Order Active LPF Response
*[Appeared in: 2017 Q8(b)]*

A single RC section gives a 1st-order filter with a roll-off of $-20\text{ dB/decade}$. To build a higher-order filter for a steeper roll-off, we cascade active stages.

A **3rd-Order Active LPF** is built by cascading a 2nd-order Sallen-Key stage directly into a 1st-order stage. Because active filters don't load each other, the maths simply add up perfectly.

### Frequency Response Characteristics
If designed with identical $R = 10\text{ k}\Omega$ and $C = 0.1\ \mu\text{F}$:
- **Cutoff Frequency ($f_c$):**

$$
f_c = \frac{1}{2\pi R C} = \frac{1}{2\pi (10\text{k})(0.1\mu)} \approx \mathbf{159.15\text{ Hz}}
$$

- **Passband ($f < 159\text{ Hz}$):** The signal passes through with a flat gain.
- **Stopband Roll-off:** Because it is a 3rd-order filter ($n=3$), the asymptotic slope in the stopband is $-20n\text{ dB/decade}$.

$$
\text{Slope} = -20(3) = \mathbf{-60\text{ dB/decade}}
$$

  *(Or equivalently, $-18\text{ dB/octave}$).*

## ⚡ Exam Tips
- For the comparison matrix, always lead with **"No inductors"** and **"Provides Gain."** Those are the two most critical advantages of active filters.
- Know the exact asymptotic roll-off slopes: 1st order is $-20\text{ dB/decade}$, 2nd order is $-40\text{ dB/decade}$, 3rd order is $-60\text{ dB/decade}$.
