# Schmitt Trigger & Hysteresis
> **Topic:** Op-Amp Applications | **Priority:** 🔴 CRITICAL | **Exam Frequency:** 5/8 years

## 1. The Problem: Comparator Chattering
*[Appeared in: 2019 Q4(c), 2018 Q4(c)]*

A standard op-amp comparator compares an input voltage against a single reference threshold. If the input is higher, the output goes to $+V_{sat}$. If the input is lower, the output goes to $-V_{sat}$.

**The Flaw:** Real-world analog signals are noisy. If a slow-moving, noisy signal crosses the threshold voltage, the tiny noise spikes riding on top of the signal will cause it to repeatedly cross back and forth across the exact threshold line. 
This causes the op-amp output to violently switch back and forth between $+V_{sat}$ and $-V_{sat}$ multiple times before the main signal finally clears the threshold area. This is called **Chattering**, and it destroys digital logic circuits reading the output.

---

## 2. The Solution: Hysteresis via Schmitt Trigger
To fix chattering, we use a **Schmitt Trigger**. A Schmitt trigger is simply a comparator with **Positive Feedback**.

By feeding a fraction of the output voltage back to the non-inverting terminal, the circuit creates *two different threshold voltages* instead of one:
1. **Upper Trigger Point ($V_{UT}$):** The threshold the input must cross when rising.
2. **Lower Trigger Point ($V_{LT}$):** The threshold the input must cross when falling.

**How it stops chattering:**
Imagine the output is at $-V_{sat}$. The threshold is currently at $V_{UT}$ (e.g., $7\text{V}$). The noisy input rises and finally hits $7\text{V}$. The output instantly snaps to $+V_{sat}$. 
Because of the positive feedback, the moment the output flips, the threshold *instantly drops* to $V_{LT}$ (e.g., $3\text{V}$). 
Even if the noisy input wobbles around $6.9\text{V}$, it doesn't matter! The threshold is now way down at $3\text{V}$. The output stays completely stable at $+V_{sat}$. The input would have to drop all the way back down to $3\text{V}$ to make it switch back.

This memory effect — where the threshold depends on the current output state — is called **Hysteresis**. The hysteresis width is $V_{UT} - V_{LT}$.

## 3. Worked Schmitt Trigger Design
*[Appeared in: 2020 Q8(c)]*

This is a classic 6-mark design question.

**Problem Details:**
Design an inverting Schmitt trigger with an Upper Trigger Point $V_{UT} = 7\text{ V}$, and a Lower Trigger Point $V_{LT} = 3\text{ V}$. Assume the op-amp saturation voltages are $\pm 14\text{ V}$.

### Step 1: The Circuit Setup
An inverting Schmitt trigger applies the input $V_{in}$ to the inverting (-) terminal. 
The non-inverting (+) terminal is connected to a voltage divider consisting of a feedback resistor $R_F$ (coming from the output) and an input resistor $R_1$ (connected to a reference DC voltage $V_{ref}$).

### Step 2: The Threshold Equations
The voltage at the non-inverting terminal determines the threshold. By superposition of $V_{ref}$ and $V_{out}$:
$$
V_{threshold} = V_{ref} \left( \frac{R_F}{R_1 + R_F} \right) + V_{out} \left( \frac{R_1}{R_1 + R_F} \right)
$$

When $V_{out} = +V_{sat} (+14\text{V})$, the threshold is pulled up to $V_{UT}$:
$$
V_{UT} = V_{ref} \left( \frac{R_F}{R_1 + R_F} \right) + 14 \left( \frac{R_1}{R_1 + R_F} \right) = 7\text{ V} \quad \text{--- (Eq. 1)}
$$

When $V_{out} = -V_{sat} (-14\text{V})$, the threshold is pulled down to $V_{LT}$:
$$
V_{LT} = V_{ref} \left( \frac{R_F}{R_1 + R_F} \right) - 14 \left( \frac{R_1}{R_1 + R_F} \right) = 3\text{ V} \quad \text{--- (Eq. 2)}
$$

### Step 3: Solve for the Resistor Ratio
We want to eliminate $V_{ref}$ to find the ratio between $R_1$ and $R_F$. 
**Subtract** Eq. 2 from Eq. 1:
$$
14 \left( \frac{R_1}{R_1 + R_F} \right) - \left( -14 \left( \frac{R_1}{R_1 + R_F} \right) \right) = 7\text{ V} - 3\text{ V}
$$
$$
28 \left( \frac{R_1}{R_1 + R_F} \right) = 4
$$
$$
\frac{R_1}{R_1 + R_F} = \frac{4}{28} = \frac{1}{7}
$$

Cross-multiply:
$$
7 R_1 = R_1 + R_F
$$
$$
\implies \mathbf{R_F = 6 R_1}
$$

*Design Choice:* Let's pick a standard value for $R_1$, say **$10\text{ k}\Omega$**.
Therefore, **$R_F = 60\text{ k}\Omega$**.

### Step 4: Solve for the Reference Voltage ($V_{ref}$)
Now that we know the ratio $\frac{R_F}{R_1 + R_F} = \frac{6R_1}{7R_1} = \frac{6}{7}$, we can plug it back in.
**Add** Eq. 1 and Eq. 2 to eliminate the $14\text{V}$ term:
$$
2 V_{ref} \left( \frac{R_F}{R_1 + R_F} \right) = 7\text{ V} + 3\text{ V} = 10\text{ V}
$$
$$
V_{ref} \left( \frac{6}{7} \right) = 5\text{ V}
$$
$$
V_{ref} = 5 \times \frac{7}{6} = \frac{35}{6} \approx \mathbf{5.83\text{ V}}
$$

### Final Design
- Op-Amp inverting terminal: Connected to $V_{in}$
- Op-Amp non-inverting terminal: Connected to a junction.
- $R_F = 60\text{ k}\Omega$ connects the non-inverting terminal to the Output.
- $R_1 = 10\text{ k}\Omega$ connects the non-inverting terminal to a DC supply of $+5.83\text{ V}$.

## ⚡ Exam Tips
- The mathematical trick to solving the design problem quickly is **Adding** the two equations to find $V_{ref}$, and **Subtracting** the two equations to find the resistor ratio.
- "Hysteresis" and "Schmitt Trigger" are synonymous in exam questions. If they ask how to fix chattering, the answer is always adding positive feedback to create hysteresis.
