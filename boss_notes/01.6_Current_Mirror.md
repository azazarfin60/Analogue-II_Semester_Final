# Current Mirror & Wilson Current Mirror
> **Topic:** Multistage Amplifiers / IC Biasing | **Priority:** 🔴 CRITICAL | **Exam Frequency:** 6/8 years

## Why Current Mirrors?

Inside integrated circuits, resistors are expensive — they take up enormous chip area. A 100 kΩ resistor might need more silicon than 1000 transistors! So IC designers replace bias resistors with *transistors configured as constant current sources*. The current mirror is the most fundamental of these.

The lecture (All About Electronics) explains: "In a current mirror, Q1 is diode-connected — its collector is shorted to its base — forcing it to operate in the active region. This sets up a $V_{BE}$. Since Q2 has the exact same $V_{BE}$, it conducts the exact same current. The output current *mirrors* the reference current."

---

## Basic Two-Transistor Current Mirror

### The Circuit

```
                  +V_CC
                   |
                  [R]
                   |
        I_ref ----+------------+
                   |            |
                  Q1 (diode)   Q2 (mirror)
                   |            |
                  GND          GND → I_out (to load)
```

Q1 has its collector shorted to its base — this is called "diode-connected" because it behaves like a diode (only conducts in one direction with a fixed $V_{BE}$ drop).

### How It Works — Step by Step

**1.** The reference resistor $R$ sets a reference current:

$$I_{ref} = \frac{V_{CC} - V_{BE}}{R}$$

**2.** This current flows through diode-connected Q1, establishing a specific $V_{BE}$:

$$V_{BE} = V_T \ln\left(\frac{I_{ref}}{I_S}\right)$$

**3.** Since Q1 and Q2 have their base and emitter terminals connected in parallel, they share the **exact same** $V_{BE}$.

**4.** If the transistors are perfectly matched ($I_{S1} = I_{S2}$), Q2 conducts the exact same current:

$$I_{out} = I_S \cdot e^{V_{BE}/V_T} = I_{ref}$$

The output "mirrors" the reference. Change $R$ to change $I_{ref}$, and $I_{out}$ follows automatically.

### The Finite $\beta$ Error

In reality, the base currents are NOT zero. Both Q1 and Q2 draw base current from the reference:

$$I_{ref} = I_{C1} + I_{B1} + I_{B2} = I_C + \frac{I_C}{\beta} + \frac{I_C}{\beta} = I_C\left(1 + \frac{2}{\beta}\right)$$

$$\boxed{I_{out} = I_C = \frac{I_{ref}}{1 + 2/\beta}}$$

**Exam Proof (frequently asked):** Show that $I_{B1} = \frac{I_{control}}{\beta + 2}$:

Starting from the shared base node:
- Control current = $I_{C1} + I_{B1} + I_{B2}$
- Since matched: $I_{B1} = I_{B2}$ and $I_{C1} = \beta I_{B1}$

$$I_{control} = \beta I_{B1} + 2I_{B1} = (\beta + 2)I_{B1}$$

$$\boxed{I_{B1} = \frac{I_{control}}{\beta + 2}}$$

For $\beta = 100$: error is $\frac{2}{102} \approx 2\%$. Not terrible, but not great for precision circuits.

---

### Negative Feedback Self-Stabilization

The current mirror has built-in negative feedback. Your class notes describe it in Bengali as "same হয়ে যাবে" (it will become the same). Here's the chain:

$$I_L \uparrow \;\to\; I_{C2} \uparrow \;\to\; I_{B2} \uparrow \;\to\; V_{BE2} \uparrow \;\to\; V_{BE1} \uparrow \;\to\; V_{CE1} \uparrow \;\to\; I_{control} \downarrow \;\to\; I_B \downarrow \;\to\; I_{B2} \downarrow \;\to\; I_L \downarrow$$

The disturbance self-corrects!

## Wilson Current Mirror (3-Transistor)

The Wilson mirror dramatically improves accuracy by reducing the base current error from $2/\beta$ to $2/\beta^2$. It uses a third transistor Q3 in a feedback arrangement.

### The Circuit

```
                       I_out (to load)
                         |
                        Q3
                         |
           +-------------+-------+
           |                     |
          [R]                    |
           |                     |
        Iref ---> Q1 ----------- Q2
           |      |              |
           +------+              |
           |                     |
          GND                   GND
```

### How It Works

Q3 is in series with the output. Its emitter current feeds Q2 (diode-connected) and the bases of Q1/Q2. If the output current tries to rise, Q2 conducts more, which pulls down Q3's base voltage, which reduces Q3's collector current — negative feedback restores the balance.

### Mathematical Derivation

**Step 1:** Q1 and Q2 form a basic mirror, so $I_{C1} = I_{C2} = I_C$.

**Step 2:** Q3's emitter current feeds both Q2's collector and the bases of Q1 and Q2:

$$I_{E3} = I_{C2} + I_{B1} + I_{B2} = I_C + \frac{2I_C}{\beta} = I_C\left(1 + \frac{2}{\beta}\right)$$

**Step 3:** The output current is Q3's collector current:

$$I_{out} = I_{C3} = \frac{\beta}{\beta+1} I_{E3} = \frac{\beta}{\beta+1} \cdot I_C\left(1 + \frac{2}{\beta}\right)$$

$$I_{out} = I_C \cdot \frac{\beta + 2}{\beta + 1}$$

**Step 4:** After substitution and simplification:

$$\boxed{I_{out} = I_{ref} \cdot \frac{1}{1 + \frac{2}{\beta^2 + \beta}}}$$

For $\beta = 100$: error = $\frac{2}{10100} \approx 0.02\%$ — a hundred times better than the basic mirror!

---

### Worked Numerical: Wilson Current Mirror
*[2017 Q3(b)]*

**Given:** $V_{CC} = 6\text{ V}$, $R = 1.3\text{ k}\Omega$, $\beta = 100$, $V_{BE} = 0.7\text{ V}$.

**Step 1: Reference current.** The path includes R, Q1's $V_{BE}$, and Q3's $V_{BE}$:

$$I_{ref} = \frac{V_{CC} - V_{BE1} - V_{BE3}}{R} = \frac{6 - 0.7 - 0.7}{1.3\text{k}} = \frac{4.6}{1300} \approx 3.538\text{ mA}$$

**Step 2: Output current:**

$$\text{Error} = \frac{2}{\beta^2 + \beta} = \frac{2}{10100} \approx 0.000198$$

$$I_{C3} = 3.538 \times \frac{1}{1.000198} \approx 3.537\text{ mA}$$

**Step 3:** Current through Q2 = $I_{C2} \approx 3.537\text{ mA}$, Current through Q3 = $3.537\text{ mA}$.

## ⚡ Exam Tips & Common Mistakes

1. **Two base currents in the formula!** The denominator is $\beta + 2$ (NOT $\beta + 1$), because TWO transistors draw base current from the reference.
2. **Wilson has TWO $V_{BE}$ drops in the reference path** — don't forget: $I_{ref} = (V_{CC} - 2V_{BE})/R$.
3. **"Explain the function"** = say it replaces resistors in ICs for biasing, and the output current *mirrors* the reference current regardless of the load.
